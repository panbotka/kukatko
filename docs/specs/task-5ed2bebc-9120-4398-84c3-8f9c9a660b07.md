# Neither the CLI nor the agent interface knows anything about video

Two client surfaces have been left behind by the streaming work.

**The CLI.** The command-line client covers the curation write surface and can rebuild a photo's
thumbnails, embedding, faces and place. It cannot ask for a video to be prepared for playback, it
cannot rebuild a scrub preview, and it has no command for the library-wide encode backfill — that
backfill is reachable only over HTTP. An operator repairing a library has to reach for curl for
this one thing and nothing else.

**The agent interface.** The photo detail it exposes carries a duration and nothing else about a
video: no encode state, no frame rate, no codecs, no indication whether the clip has sound. The
photo summary does not even carry the duration. An agent asked "which videos still need
preparing" or "how long is that clip" cannot answer from what it is given.

## Requirements

### CLI

- A command to prepare one video for playback, alongside the existing per-photo rebuild commands
  and named consistently with them.
- A command for the library-wide encode backfill, alongside the other backfill commands.
- A command to rebuild one video's scrub preview.
- A way to see a video's renditions — which qualities exist, how large they are, when they were
  encoded — in the table, JSON and agent-readable output forms the client already supports.
- Follow the client's own conventions for irreversible work and for output format. Note that a
  subcommand's own output flag will shadow the global format flag if it reuses the same short
  letter — do not reintroduce that clash.

### Agent interface

- The photo detail gains a video's encode state, frame rate, video and audio codec, and whether it
  has sound. The photo summary gains the duration, so a listing of videos is useful without a
  detail call per item.
- Keep to what the interface is for: reporting and reading. Nothing here should let an agent start
  an expensive encode unless that fits the existing rule about which tools are exposed — check
  what the interface documentation says is deliberately withheld and respect it, rather than
  adding a tool because it is possible.

## Documentation

The CLI commands go into the operations documentation with the other commands; the agent
interface changes into its own document, including the reasoning about what was deliberately not
exposed.

## Tests

Command tests against a fake server for each new CLI command, covering the output forms; shape
tests for the agent payloads with a still, a video with sound and a video without.
