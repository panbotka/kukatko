# Library toolbar: highlighted stepper value and a tiny "?" help icon

UI/UX review findings #28 and #29 (2026-10-11). In the library toolbar the tiles-per-row stepper renders as "– | ▦ 10 | +" where the middle value box is filled with the teal accent as if it were an active toggle, while the +/– buttons are plain. Next to the search field the query-language help is a 16px "?" icon button with low contrast that is easy to miss.

## Requirements
- Stepper: the value box is a plain, non-highlighted segment (same background as the +/– buttons, text in the normal foreground colour); it stays non-interactive and keeps its grid icon. The disabled state of +/– at the range limits stays visible.
- Help: the "?" becomes a regular 32px (desktop) / 44px (touch) icon button in the app's standard icon-button style, with aria-label "Nápověda k vyhledávacímu jazyku" and a tooltip; it keeps opening the query-help modal.
- Apply to every page using the toolbar (library, favourites, album/label detail, trash, person detail stepper).
- Tests: the stepper value element no longer carries the active/accent class; the help button renders with the standard icon-button class.
