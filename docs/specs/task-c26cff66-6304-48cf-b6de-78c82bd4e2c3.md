# Favourites page: a heart on every tile is noise

UI/UX review finding #25 (2026-10-11). Photo tiles show a filled pink heart overlay when the photo is a favourite. On `/favorites` every tile is a favourite by definition, so every tile carries the heart and the overlay stops carrying information.

## Requirements
- On the favourites page the persistent heart overlay is not rendered; the heart button still appears on hover/focus (desktop) and in the tile's touch controls, so a photo can still be un-favourited from there.
- Everywhere else (library, albums, person gallery…) the behaviour is unchanged.
- Implement via a prop/option on the tile or grid component, not a page-specific CSS hack.
- Tests: FavoritesPage renders tiles without the persistent heart; LibraryPage still renders it for favourites.
