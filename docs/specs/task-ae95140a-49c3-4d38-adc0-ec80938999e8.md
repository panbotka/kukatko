# The system dashboard tells you how the video encoding is going

The admin system page has a job queue table with a row per job type, and the streaming encode
already appears there. That row is about *jobs* — and because finished job rows are kept, its
totals are lifetime tallies, not a backlog. It cannot answer the question an operator actually
has: how many videos in this library still have no streaming version, and is the queue moving.

## Requirements

Extend the aggregated system status with a video section, and render it on the system page.

- What the section reports:
  - how many videos the library holds, and how many of them have at least one encoded streaming
    rendition;
  - how many have none, broken down by what is happening to them: an encode queued, an encode
    running, an encode that failed or is dead-lettered, and videos that were never enqueued at
    all (the case that silently stalls, and the reason this section exists);
  - how long the oldest waiting encode has been waiting;
  - how many renditions exist in total and how much storage they occupy, if that is available
    without a second expensive query;
  - whether streaming is switched on for this instance at all — with it off, "no video has a
    streaming version" is the correct state, not a backlog, and the section must say so rather
    than showing a scary number.
- The videos still lacking a streaming version also become an entry in the existing remaining-work
  backlog list, alongside the other backlogs there, so the operator sees it without scrolling to
  a dedicated card. Suppress that entry when streaming is switched off.
- Cost: the dashboard aggregation is one memoised round trip today and must stay that way. Fold
  the new counts into the existing statement rather than adding queries; verify on the test
  database that no new per-row or per-video query appears.
- The same maintainer guard as the rest of the system status.
- The system page renders the section in keeping with the cards already there — same card and
  table idiom, no new visual language. It reads correctly with zero videos in the library.

## Texts

Czech default, English second, both filled.

## Out of scope

- A search filter for "videos without a streaming version". The backlog entry may link to the
  plain video search; a dedicated query token is separate work.
- Any change to how encoding is scheduled or retried. This task only reports.
