# Bulk Set Location

The photo detail offers picking a photo's location on a map via a reusable map-picker component. Extend it to selections: one pick applies to a whole batch of scanned photos from the same place. If no map-picker component exists in the codebase, stop and end the task as blocked instead of building a second one.

## Requirements

- The bulk actions for a selection gain "Set location": opens the same map picker; confirming applies the coordinates to all selected photos.
- The confirmation states clearly how many of the selected photos already have a location, and offers a choice: overwrite them too, or skip them and only fill the empty ones.
- The write goes through the bulk-edit path (whole batch in one transaction, audited — the internal/bulk convention), not through per-photo requests.
- Backend: extend the bulk edit contract with coordinates if it doesn't accept them yet (validate lat −90..90, lng −180..180).
- Follow-up derived work (places reverse-geocode job, sidecar rewrites) is enqueued for every affected photo, same as a single-photo location edit.
- A manually picked location is authoritative — never flagged as an estimate.
- Editor role and above only; cs (default) + en i18n.
- Tests: integration for the bulk path incl. the skip-existing option; component test for the bulk action wiring.
