# Viewer title truncates to a single character on 1024px with the info panel open

UI/UX review finding #12 (2026-10-11). In the photo viewer at a tablet-landscape width (1024×768) with the info panel open, the top bar has the back button, the title ("15. 8. 2026 23:40 · Lhota 12") and the full toolbar in the remaining ~600px. The title gets squeezed to "1…", which is useless.

## Requirements
- Define a minimum useful width for the title (about 140px). When the toolbar and the title cannot both fit, hide the title entirely (it is repeated in the info panel) instead of truncating it below that width; keep the back button.
- Alternatively, below a width threshold move the title under the top bar as a second thin row; either way, never render a one-character title.
- The title stays as today at desktop widths with the panel closed and at phone widths (where the phone layout already has its own arrangement).
- Add a test for the collapsed-title state.
