# /maintenance and /import show queue numbers nobody can act on

Both pages render a cut-down copy of the job-queue view that `/system` does properly, and neither
links to it.

## Background

`pages/MaintenancePage.tsx:320` defines `JobStatsBar` (rendered at `:651`), and
`pages/ImportPage.tsx:107` holds a second copy of the same badge row (rendered at `:358`).
`components/system/JobQueuePanel.tsx:146-153` on `/system` exists because this shape was judged
misleading: it adds the per-type × per-state split and a requeue button on each dead-letter row.

- The maintenance copy shows a `Total` taken from `JobStats.total` (`services/import.ts:99`).
  **Verify first** whether that figure counts finished jobs. If it is a lifetime total, the badges do
  not add up and a maintainer reads a backlog many times the size of the library. Report what you
  find; the rest of this task stands either way.
- The import copy has no `Total`, but also no per-type breakdown, and shows a `dead` count with no
  requeue control.
- Neither page links anywhere: `MaintenancePage.tsx` contains no `to="/…"` at all.

## Requirements

- Neither page keeps a private copy of the queue summary. Replace each badge row with a link to
  `/system`, styled the way `pages/SystemStatusPage.tsx` links elsewhere, so the one place that can
  act on the queue is a tap away.
- If a page genuinely needs numbers inline, share `JobQueuePanel` rather than keep a second reduced
  rendering of the same data. Decide, do one, and say which.
- No figure that cannot be acted on is left on either page. A `dead` count with no route to a requeue
  in particular is not acceptable.
- `/system` is maintainer-only and so are both these pages — confirm that holds, so the new link
  never leads somewhere the reader cannot go.

## Testing

- Both pages render the link and no longer render the badge row; a maintainer reaches `/system` from
  each.
- `JobQueuePanel` and `SystemStatusPage` tests untouched.
- If `JobQueuePanel` gains a new host, cover it there.

## Docs

- `docs/FRONTEND.md`: drop `JobStatsBar` from the maintenance and import page descriptions and say
  where the queue is read instead.
- `CLAUDE.md` needs no change.
