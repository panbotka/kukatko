# Technical details on every photo show a SHA256, a PhotoPrism UID and raw coordinates

The expanded "Technické údaje" of a photo contain, next to genuinely useful things
(dimensions, size, format, date):

- "Formát: JPEG" **and** "Kodek obrazu: jpeg" — the same fact twice,
- "Otisk (SHA256): 414a4fc8c2b2…",
- a **PŮVOD** section with "PhotoPrism UID: pt8qxy9y3nuwqef2",
- and, in the Informace panel under the mini-map, raw coordinates "49.39322, 16.70869".

None of this is usable by the person looking at a family photo, and all of it reinforces the
feeling that the app is for technicians.

## Requirements
- Merge "Kodek obrazu" into "Formát" so the same fact is not stated twice.
- Move the SHA256 fingerprint and the PhotoPrism/photo-sorter UIDs into a collapsed "Pro
  vývojáře" section, collapsed by default.
- Replace the raw coordinates under the mini-map with the place name, keeping the numbers as
  a hover title (or inside the developer section).
- Czech and English translations for the new section.

## Where it is
`web/src/components/photo/TechnicalDetails.tsx`,
`web/src/components/photo/PhotoLocation.tsx`.

## Out of scope — important
`photos.photoprism_uid`, `photoprism_file_hash` and `photosorter_uid` are **live data**, not
import leftovers: they back uid search and every metadata sidecar. Do not drop the columns and
do not stop returning them from the API — this task only changes how prominently the UI shows
them. No data changes.
