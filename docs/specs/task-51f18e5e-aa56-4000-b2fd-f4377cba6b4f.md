# Show who uploaded a photo through an upload link

Found in the v0.28 prerelease walkthrough (staging, commit 4aa69a3). The "Od koho?" name a guest
types on the public upload page is stored in `upload_link_photos.uploader_name` (verified in the
DB), but nothing surfaces it: the photo detail API (`GET /photos/{uid}`) has no such field and the
UI never shows it, so a curator cannot tell who sent a photo. The audit trail likewise shows
anonymous `upload_link.upload` rows with actor "—" and no hint of the link or the name.

**The name stays optional.** The public upload page must not start requiring "Od koho?" — this task
only surfaces what was typed. Every display below must handle an empty name gracefully.

## Requirements

- Do not change the public page's "Od koho?" field: still optional, uploads without a name keep
  working exactly as today.
- `GET /photos/{uid}` carries the upload-link provenance when the photo arrived through a link:
  link title (+ uid), the typed uploader name (empty/absent when none was typed), the account if
  signed in/claimed, and when. Visible to curator+ only (decide whether viewers see the name;
  document it). Absent for photos that did not come through a link.
- Photo detail info panel shows it in one line (cs + en), the link title linking to
  `/upload-links` for curators:
  - with a name: "Nahráno přes odkaz „Pouť 2026" · od: Jana"
  - with an account (signed in or claimed at registration): the account's display name
  - with neither: "Nahráno přes odkaz „Pouť 2026" · bez jména" — never an empty "od:" or a dangling separator
- A photo uploaded through several links (duplicate re-filed) shows the first/created one, or all
  — pick one and document it.
- The audit list renders anonymous `upload_link.upload` rows with the link title and the typed
  name when there is one (otherwise just the link title) instead of a bare "—".
- Optional: a `q=` filter for photos from a given link (e.g. `uploadlink:<uid>`) if it fits the
  query-language registry cheaply; otherwise skip.
- Tests: API integration (field present/absent, with and without a name, role visibility),
  frontend component test for all three info-line variants, i18n parity.

## Repro
Upload through a link signed out with "Od koho?" = "Prerelease Tester" (and once with it empty) →
open the photo detail as admin → no trace of the name or the link.
