# Search page empty state is just "Zadejte hledaný výraz."

UI/UX review finding #22 (2026-10-11). `/search` without a query shows the form and a centred sentence "Zadejte hledaný výraz." The command palette already offers "Nedávno hledané" (the per-user search history), but this page does not. The header also offers "Uložit pohled" while there is nothing to save.

## Requirements
- Empty state (no query): show the user's recent searches (same source the palette uses, up to 10) as clickable chips/rows that fill and submit the field, plus a short list of example queries as chips (e.g. `year:1965`, `person:Jarmila`, `album:"Léto 2024"`, `label:kostel`, `text:veselice`) that insert the term into the field. Keep the existing one-sentence hint.
- Hide (or disable with a tooltip) "Uložit pohled" until a query exists; the "Uložená hledání" dropdown stays.
- Phone and desktop both get the empty state; chips wrap.
- Tests: empty state renders recent searches from the history service and the example chips; clicking a chip fills the input.

## Scope and verification
- UI only: no change to search semantics; recent searches come from the existing search-history endpoint.
