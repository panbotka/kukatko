# "Počet fotek: 200" is not a count of anything the reader cares about

A search on the search page reports a photo count that is an artefact of how the ranking is
built, not a number of matching photographs — and it is presented in exactly the same words as
the library's real total.

How the number arises today:

- **Hybrid** is the default mode. It fuses the top results of two rankings, each drawn with a
  pool limit of 200, and reports the size of the fused set. So the number saturates somewhere
  between 200 and 400 and stops growing however many photographs actually match.
- **Semantic** draws a candidate pool of 500 nearest neighbours and reports the size of the
  ranked slice, so it saturates at 500.
- **Fulltext** and a plain filtered listing do a real SQL count, so their number is a true
  total.

The reader is given no way to tell these apart: all four render through the same "Počet fotek: N"
label. A saturated pool reads as "there are exactly 200 photographs of this", which is false and
which makes the library look smaller than it is.

## Requirements

- In the ranked modes, present the number as what it is — the best matches the ranking returned
  — rather than as a total. Wording is part of this task: it must stay true when the result set
  is smaller than the pool, so a phrasing that always claims a cap is no better than today's.
- In the modes that do a real count, keep saying the total plainly, as now.
- The distinction must be visible without hovering anything, because a phone has no hover.
- Both `cs` and `en` locales, keeping the existing i18n discipline (no hardcoded user-facing
  strings, both locales in step).

## Edge cases

- A ranked search returning fewer results than its pool — the wording must not imply a cap that
  was never reached.
- A ranked search combined with filters that cut the fused set down further.
- Zero results, where the existing empty state should keep speaking for itself.

## Not in this task — checked and found sound

Three neighbouring items were investigated and need no work:

- The three search entry points are already distinguished ("Hledat mezi fotkami" in the
  navigation, "Filtrovat v knihovně" in the library, "Hledaný výraz" on the search page, which
  also carries an explicit mode selector and is linked from the library's filter bar). The only
  wrinkle is that the library filter's placeholder opens with "Hledat" while its own label says
  "Filtrovat"; align that wording if it is cheap, but nothing else there needs changing.
- The circled-slash badge on a label chip already carries a tooltip and is folded into the
  chip's accessible name ("Třídění se na tenhle štítek neptá"), and it is shown only to
  editors. It cannot be reached by hover on a phone, which is worth remembering, but it is not
  unexplained.
- The per-chip label action menu is a deliberate, documented design decision — the review
  setting reads there as an action rather than as an unlabelled switch. Leave it alone.
