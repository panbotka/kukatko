# One voice in every e-mail Kukátko sends

The outgoing e-mails mix the informal and the formal Czech register. A pre-release walk caught every template in a test inbox:

- The notification mails (`internal/mailer/templates_notification.go`: `comment_mention`, `task_assigned`, `album_featured`, `tagged`) open "Ahoj, <Name>," and use "tě / ti / můžeš".
- The account mails (`internal/mailer/templates.go`: `project_setup`, `project_admin_added`, registration received, registration pending for admins, approval, password reset) use "Dobrý den" and "vás / vám".
- The `tagged` mail mixes both registers in **one text**: it says "Ahoj, … vás někdo označil … Tenhle e-mail ti chodí, protože sis ho zapnul(a)". Its subject is "Označili vás na fotce", while the other notification subjects say "tě".
- The greeting puts the full display name in the nominative ("Ahoj, Pavla Pětková,", "Dobrý den, Jana Šestáková,"), which reads awkwardly in Czech.

## Requirements

- Pick **one** register for all e-mails and apply it to every subject and body: the formal "vy" (Dobrý den, vás, můžete). It is the safer choice for mail that reaches people the sender may not know, such as a new project owner or a registrant. If the codebase or `docs/UX_AUDIT.md` records a deliberate decision for the informal voice in the app UI, keep the UI as it is; this task is about e-mail only.
- Gender-neutral wording stays (e.g. "přidal(a)").
- Greeting: drop the name from the greeting line ("Dobrý den,") instead of risking a wrong vocative. Alternatively use the name only where it does not need declension.
- Keep every link, fact and the "how to switch this mail off" footer. Only the wording changes.
- Update the template tests (golden texts) and add one test that fails if any template contains an informal marker ("Ahoj", " tě ", " ti ", "můžeš", "sis ") alongside the formal one, or the other way round.
- Docs: wherever `docs/` quotes a mail text, update it.

Use only invented names and `example.com` addresses in tests.
