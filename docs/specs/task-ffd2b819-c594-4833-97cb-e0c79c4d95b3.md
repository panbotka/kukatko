# Recalibrate similarity thresholds after the SigLIP 2 migration

Cosine distances from SigLIP 2 are not distributed like CLIP's, so every tuned distance constant now means something different than it did when it was chosen. Duplicate detection is the visible casualty: it will keep working, but at the wrong sensitivity.

## Context

- **Depends on task `f8e17eab-ea3f-453a-839c-1aca1a29a891`** (the 768 → 1152 migration). Do not start until every photo has a 1152-dim embedding — no rows missing, and `embeddings.model` reporting the SigLIP 2 tags.
- Background on the model change: **kozaktomas/image-embeddings#3**, merged as `7debc4d`, deployed 2026-08-11. The sidecar now serves `ViT-SO400M-14-SigLIP2-378` / `webli` at 1152 dims in fp16; confirm with `GET /health` → `clip.dim`.
- Why the thresholds move: SigLIP 2 is trained with a sigmoid loss rather than CLIP's softmax contrastive loss, so the similarity distribution has a different shape and spread. The numbers are not transferable; only the *behaviour* they were chosen to produce is.
- The existing thresholds were tuned against ViT-L-14 vectors and have never been re-derived, so there is no recorded method to repeat. Leaving one behind is part of this task.

## Requirements

- Find every tuned cosine-distance constant on the image-embedding path — at minimum the duplicate-detection maximum distance — and list each with its current value and where it is configured.
- For each, measure the new distribution on real data instead of guessing: sample pairs from the library, report the distance distribution, and choose a threshold that reproduces the previous *behaviour* (how many pairs get flagged), not the previous *number*.
- Report precision on a hand-checked sample: take the pairs the new threshold flags as duplicates and record how many genuinely are. Report the number found, do not assert that it is fine.
- Update the defaults and document each new value together with the measurement that produced it, so the next model change has a method to follow rather than a mystery constant.
- Face thresholds are out of scope — InsightFace did not change and still returns 512-dim vectors.

## Acceptance

- Duplicate detection flags a comparable number of pairs to before the migration, with hand-checked precision reported.
- Every changed constant has its old value, new value and the measurement written down next to it.
