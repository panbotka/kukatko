# Login page: card glued to the top, no app name

UI/UX review finding #20 (2026-10-11). `/login` renders a card ("Přihlášení", username, password, orange submit) at the very top of the page with a huge empty area below, on desktop (1440×900) and on phones alike. Nothing on the page says "Kukátko".

## Requirements
- The login card is vertically centred in the viewport on desktop and tablets (with a sensible maximum width as today); on phones it keeps a top margin of about 10–15% of the viewport so the keyboard does not push it off-screen.
- Add the app name above the card: "Kukátko" as a wordmark (text with the display font and the brand colour from the palette; an inline SVG icon is optional, no external asset). The card title can then be simply "Přihlášení".
- The same frame is used by the registration and password-reset pages so all three look alike.
- Keep every existing element (passkey button, registration link when enabled, error messages) and their behaviour.
- Update LoginPage/RegisterPage/PasswordResetPage tests if they assert on the heading structure.
