# Person detail: orphaned "N obličejů ke kontrole" button and danger-looking family pills

UI/UX review finding #18 (2026-10-11). On `/people/:uid` the outline button "⚠ 8 obličejů ke kontrole" (link to the outliers tool) sits alone at the very bottom of the page under the "Možná je i zde" block, far from the other person tools (Upravit, Sloučit s jinou osobou) in the header. The "Rodina" block renders relatives as filled pink pills, a hue that otherwise means danger/delete in the app, so they read as warnings.

## Requirements
- Move the "N obličejů ke kontrole" button into the header action group next to "Upravit" and "Sloučit s jinou osobou" (same outline style; keep the warning icon and the count; render it only when N > 0 as today). On phones it wraps with the other header actions.
- Family relative pills use a neutral/secondary chip style (surface + border, avatar, name) rather than the pink fill; the "add relative" circular buttons next to them keep their style. The pills remain links to the relative's page.
- On phones, stack each relation label ("Rodiče", "Sourozenci", …) above its pills so the label does not float next to a wrapped row.
- Palette tokens only; update PeoplePage/subject detail tests that look for the button position or pill class.
