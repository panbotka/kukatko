`web/src/hooks/usePhotoShare.test.tsx` → `usePhotoShare > does nothing when the selection resolves to no files at all` fails intermittently with:

```
AssertionError: expected 'manifest' to be 'idle' // Object.is equality
```

It blocks releases. On 2026-09-11 it failed **two separate gates on the same green commit** (`7a6238a`):

- CI run: https://github.com/panbotka/kukatko/actions/runs/34568884315 (passed on re-run)
- The `v0.19.0` tag's Docker Build & Publish: https://github.com/panbotka/kukatko/actions/runs/34572749844 (passed on re-run, but a failed publish means the release image is briefly missing from GHCR while the vps PR is already open)

## Not a regression

`usePhotoShare` was last touched in `7f45fb7` (2026-08-17), well before `v0.18.1`, and was untouched by the whole `v0.18.1..v0.19.0` range. It has been observed flaking at roughly 1 in 3 runs, including in isolation.

## The shape of it

The hook is observed in state `manifest` when the test expects it to have settled back to `idle`. For a selection that resolves to no files, the hook evidently still enters its manifest-fetching state briefly before settling, and the assertion races that transition rather than waiting for the settled state.

## What to do

1. Reproduce it locally first — run the single test repeatedly until it fails, e.g.
   `cd web && npx vitest run src/hooks/usePhotoShare.test.tsx -t "no files at all" --repeat 20`
   (run vitest from `web/`, never from the repo root — a bare `npx vitest` at the root picks up a cached copy with no jsdom and produces mass bogus failures).
2. Decide whether the **test** or the **hook** is wrong. Either is a legitimate outcome:
   - If an empty selection *should* short-circuit without ever entering `manifest`, the hook has a real (if harmless) bug — fix it so it never leaves `idle`, and the assertion becomes correct as written.
   - If entering `manifest` briefly is correct, the test must wait for the settled state (`waitFor`) instead of asserting on a snapshot taken mid-transition.
   Prefer the first if the empty case can be detected before any async work starts — it is the stronger fix and removes a pointless state flip.
3. Check the sibling cases in the same file for the same racing pattern; fix any that share it.
4. Do NOT simply add a retry, bump a timeout, or mark the test skipped.
