# Watching the storage move in the app

## Context

Kukátko is multi-tenant. Maintainer API: `GET /api/v1/projects/{uid}/rekey` → `{state: running|paused|done|failed, total_photos, done_photos, total_bytes, done_bytes, last_key, error_count, errors: [{key, message, at}], started_at, updated_at, finished_at}` or 404 when no run; `POST …/rekey` (start; 409 `already_running`/`already_prefixed`), `…/pause`, `…/resume`, `…/retry`. The page `/system/projects/:slug` exists with a placeholder "Úložiště" section showing `storage_prefix`. The owner wants to **see the progress in the app**. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 5.3; read `docs/FRONTEND.md`. Step 35 of 40.

## Requirements

- "Úložiště" section states:
  - **Root, no run:** text "Objekty tohoto projektu leží v kořeni úložiště. Přesun je bezpečný: každý soubor se nejdřív zkopíruje a ověří, teprve potom se smaže původní." and a button "Spustit přesun" behind a confirm dialog that repeats the guarantee and says it can be paused.
  - **Run exists:** a progress card — progress bar (done/total photos, done/total bytes human-readable, percent), rate in photos/min (computed client-side from the last two polls) and ETA, state badge (running/paused/done/failed), started/updated, last key (monospace, middle-truncated), error count with an expandable list of the last errors; buttons: Pozastavit (running), Pokračovat (paused), Zkusit znovu (failed). **Done:** success summary with the new prefix and the finish time.
- Polling: every 3 s while running, 15 s otherwise, suspended while `document.hidden`, stopped on done.
- `/system/projects` list: a chip "přesun 42 %" next to a project with a running/paused move.
- Service `web/src/services/rekey.ts` via `instancePath`; react-bootstrap `ProgressBar`; i18n cs + en; palette tokens only; `Icon` only.
- Tests (Vitest): the four states; confirm gates Start; polling cadence with fake timers (`shouldAdvanceTime: true` — see `docs/FRONTEND.md` testing notes) and the hidden-tab suspension; rate/ETA helper unit tests; the list chip.
- Docs: `docs/FRONTEND.md`, `docs/OPERATIONS.md` (link the runbook to the page), `README.md`.

## Out of scope

Backend changes.
