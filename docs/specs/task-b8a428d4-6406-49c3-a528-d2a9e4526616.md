# Refine the mobile hamburger menu into a clean, thumb-friendly drawer

On a phone, opening the hamburger expands every nav group inline into one long,
nested list. It works but is cramped and hard to scan. Polish the collapsed mobile
menu so it reads as clear sections with comfortable touch rows.

## Current behavior

- `web/src/components/Layout.tsx` uses a react-bootstrap `Navbar expand="md"` with
  `Navbar.Collapse`. Because react-bootstrap disables Popper inside a Navbar, all the
  nav-group dropdowns (Procházet / Nástroje / Provoz / Správa / user menu) render
  INLINE inside the burger on mobile — so the open menu is a long flat/nested stack of
  links + expanded dropdowns with no clear grouping, section headings, or dividers.

## Requirements

- Restructure the collapsed mobile menu so it is easy to scan and operate one-handed:
  - Visually group the items into labelled sections (e.g. Procházet, Nástroje,
    Provoz, Správa, account) with clear section headers and/or dividers, instead of
    one undifferentiated list.
  - Comfortable ≥44px tap rows with adequate spacing; active-route highlighting.
  - The menu must close automatically after the user taps a destination (navigate =
    dismiss), and be easy to dismiss (tap outside / a close affordance).
  - Consider rendering the mobile menu as an Offcanvas drawer (react-bootstrap
    `Navbar` supports `expand` + `Offcanvas`) so it slides in as a proper panel and
    scrolls cleanly when tall — but only if it keeps all current items and their RBAC
    gating (Provoz = maintainer, Správa = admin) intact.
- Respect safe-area insets so the drawer/menu content isn't hidden behind the notch or
  home indicator.
- Preserve the exact set of items and their role-gating; this is a presentation/UX
  refinement, not a change to what appears.
- Desktop (`md`+) navigation must be unchanged.
- Coordinate with the separate bottom-tab-bar work in spirit: the primary destinations
  may live in a bottom bar, so this menu is mainly the secondary/tools/admin/account
  items — but do NOT assume the tab bar exists; keep this menu complete on its own.

## Testing

- Add/update Vitest tests for the mobile menu structure (sections present, closes on
  navigate, RBAC items gated).
- `make check` must pass. Update `docs/FRONTEND.md`.
