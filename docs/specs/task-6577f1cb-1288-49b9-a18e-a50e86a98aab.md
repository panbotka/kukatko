# Projects table, bootstrap project and the project store

## Context

Kukátko is becoming multi-tenant: one instance will host several independent *projects* (libraries). Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md` — read sections 1, 2.1 and 2.6 before starting. This is step 01 of 40; nothing multi-tenant exists in the tree yet. The instance is **in production** (21k photos): the migration must be safe on live data, idempotent, and finish in seconds.

Conventions you must follow: uids are `<2-letter prefix>` + 24 random base32 chars (alphabet `0-9a-v`), total length 26 — see `internal/photos/uid.go` and copy its `newUID` pattern into the new package. Every mutation is audited inside its own transaction via `internal/audit` (`audit.Write(ctx, exec, Entry)`; see the memory-style note in `docs/PACKAGES.md`: stamp the entry **before** the mutate closure, since the entry is copied). New tables must be classified in `internal/reset/tables.go`.

## Requirements

- Migration `internal/database/migrations/00NN_projects.sql` (next free number). Table `projects`:
  - `uid TEXT PRIMARY KEY`
  - `slug TEXT NOT NULL UNIQUE CHECK (slug ~ '^[a-z0-9][a-z0-9-]{0,39}$')`
  - `name TEXT NOT NULL CHECK (name <> '')`, `description TEXT NOT NULL DEFAULT ''`
  - `active BOOLEAN NOT NULL DEFAULT true`
  - `storage_prefix TEXT NOT NULL DEFAULT '' CHECK (storage_prefix = '' OR (storage_prefix ~ '/$' AND storage_prefix !~ '^/'))`
  - `max_file_bytes BIGINT NULL CHECK (max_file_bytes IS NULL OR max_file_bytes > 0)`, `max_total_bytes BIGINT NULL` (same check)
  - `created_at`, `updated_at` TIMESTAMPTZ NOT NULL DEFAULT now()
- The same migration inserts the **bootstrap project** with the fixed uid **`pj0000000000000000veselice`** (26 chars, valid alphabet), slug `v`, name `Veselice`, empty description, active, empty `storage_prefix`, no limits — `ON CONFLICT (uid) DO NOTHING`.
- New package `internal/project`:
  - constants `BootstrapUID = "pj0000000000000000veselice"`, `BootstrapSlug = "v"`; a `Project` struct mirroring the row; `ValidateSlug(string) error` (format + the reserved list below); `Store` constructed over the pgx pool like other stores.
  - `Create(ctx, CreateParams{Slug, Name, Description, MaxFileBytes, MaxTotalBytes *int64}) (*Project, error)` — generates `pj…` uid, sets `storage_prefix = "projects/<uid>/"` (**a created project never has an empty prefix**; only the bootstrap row does), typed `ErrSlugTaken` on the unique violation, `ErrInvalidSlug`, `ErrInvalidName`.
  - `Get(ctx, uid)`, `GetBySlug(ctx, slug)` — typed `ErrNotFound`.
  - `List(ctx) ([]Project, error)` ordered by name.
  - `Update(ctx, uid, UpdatePatch{Name, Description *string; Active *bool; MaxFileBytes, MaxTotalBytes **int64 or an explicit "clear" flag})` — slug is **immutable** (no field for it); `storage_prefix` is changed only through `SetStoragePrefix(ctx, uid, prefix)` (validates the same CHECK rule).
  - `Usage(ctx, uid) (Usage{Photos int64; OriginalsBytes int64}, error)`: until `photos.project_id` exists (a later step), return the whole library's `count(*)`/`sum(file_size)` of non-deleted photos for `BootstrapUID` and zeros for any other uid, with a `// TODO multi-tenancy: scope by photos.project_id` comment.
  - All mutations audited: actions `project.create`, `project.update`, `project.storage_prefix`; `TargetType: "project"`, `TargetUID` = project uid; actor uid comes from the caller (parameter), since this package must not import `internal/auth`.
- Reserved slugs rejected by `ValidateSlug`: `p`, `api`, `u`, `invite`, `system`, `login`, `register`, `projects`, `account`, `healthz`, `metrics`.
- `internal/reset/tables.go`: add `projects` to the **preserved** (account-side) list; extend the existing classification test so a table missing from both lists fails.
- Tests: integration tests (`-tags integration`, against `KUKATKO_TEST_DATABASE_URL`) for every store method and error; a migration test that a freshly migrated database has exactly the bootstrap row and that running migrations twice is harmless; unit tests for `ValidateSlug` (table-driven: valid, uppercase, leading hyphen, too long, reserved).
- Docs: `docs/PACKAGES.md` entry for `internal/project`; one line in the `## Package map` of `CLAUDE.md` (keep CLAUDE.md within its line budget); a short "Projects" paragraph in the data-model section of `docs/ARCHITECTURE.md` saying the model will be completed in later steps.

## Out of scope

Membership, `project_id` on other tables, any HTTP route, any UI, any change to auth. Do not touch `users`.
