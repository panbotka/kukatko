# Organisation is scoped by project

## Context

Kukátko is multi-tenant: `albums.project_id`, `labels.project_id`, `saved_searches.project_id` and the `search_history (user_uid, project_id, query)` PK exist; `internal/photos` is scoped (convention in `docs/PACKAGES.md`: `projectUID` after `ctx`, never defaulted; foreign = 404 same shape); `auth.ProjectUIDFromContext(ctx)`; `internal/projecttest`. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, sections 2.4 and 6. Step 15 of 40.

## Requirements

- `internal/organize` (albums incl. featured/"Doporučujeme" with expiry and the collage cover, labels, per-user favourites and ratings): every method takes `projectUID`; slug uniqueness per project; adding photos to an album/label verifies **every** photo belongs to the project in one statement (a foreign uid in the batch → `ErrNotFound`, nothing added); the featured strip, the homepage collage and the album counts read only the project; favourites/ratings listings join the project's photos.
- `internal/feedback` label rejections and duplicate dismissals/confirmations: scoped through the photo/label; `internal/expand` (`GET /albums/{uid}/similar`, `GET /labels/{uid}/similar`): the per-photo kNN filters by project (denormalised `embeddings.project_id`), votes never count foreign photos.
- `internal/savedsearch`, `internal/searchhistory`: per user **and** project (the ring of 20 recent queries is per (user, project)); foreign-owner or foreign-project saved search → 404.
- API packages (`organizeapi`, `expandapi`, `feedbackapi` label/duplicate routes, `savedsearchapi`, `searchhistoryapi`) pass the project from context.
- Isolation tests: store — albums list, labels list, featured, saved searches, history; HTTP — album detail foreign → 404 same shape; add a foreign photo to an album → 404 and the album unchanged; label similar never returns foreign photos; saved search of the same user in project B invisible in A; history recorded in A not listed in B.
- Docs: `docs/PACKAGES.md`, `docs/API.md` where behaviour changed.

## Out of scope

Families, tasks, notifications, duplicates grouping, bulk.
