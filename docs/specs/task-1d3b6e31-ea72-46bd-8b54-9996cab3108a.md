# Enlarge face-marker overlay tap targets on touch (photo detail)

The clickable face-marker boxes drawn over a photo are sized to the face bounding box,
so a small face yields a sub-44px target that is hard to tap precisely on a phone, and
the hover highlight never triggers on touch.

## Current behavior

- `web/src/components/people/FaceOverlay.tsx`: each face is a `<button>` box sized to
  the normalized face bbox (not a `.btn`, so the global coarse-pointer 44px floor does
  not apply). Small faces → small tap targets; hover-based highlighting/pairing with the
  faces panel doesn't happen on touch.
- Already-mitigated context: the `FacesPanel` list rows are `list-group-item-action`
  (proper ~44px touch targets) and drive the same face selection — so the panel is a
  usable touch path today. This task is a low-priority refinement.

## Requirements

- On coarse-pointer devices, ensure each face marker is comfortably tappable: give small
  markers a minimum ~44px hit area (e.g. an invisible padded hit box centred on the
  bbox) without visually enlarging the drawn outline or overlapping neighbours badly.
- Ensure any hover-only highlight has a touch-friendly equivalent (tap to select/pair
  with the panel) — the marker and the corresponding `FacesPanel` row should stay in
  sync on touch.
- Do not change the visual bbox outline sizing or desktop behavior.
- If markers are very dense/overlapping, prefer relying on the panel and only modestly
  enlarge hit areas to avoid overlap chaos — keep it sensible.
