# The cross-cutting edges: mail, push, metrics, audit

## Context

Kukátko is multi-tenant. Projects, memberships and `/p/<slug>/` routes exist; notifications, tasks, tag notices and the digest are per project and some deep links already carry the prefix (verify, do not assume). `audit_log.project_id` exists and `audit.Entry.ProjectUID` is written when set. `/metrics` is unauthenticated. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 6. Step 37 of 40.

## Requirements

- **Mail** (`internal/mailer` templates, `internal/notifydeliver`, `taskdigestjob`, approval and invite mails): every link is `mail.base_url + /p/<slug>/…`; subjects and bodies name the project, e.g. `Kukátko · Veselice: byl(a) jste označen(a) na 3 fotkách`; the digest has one heading per project. Templates stay pure functions; extend the data structs and update golden outputs deliberately (review each diff).
- **Push** (`internal/pushjob`, `notifydeliver`): payload URL with the prefix; title prefixed by the project name; verify the service worker's click handler opens the URL as given.
- **Metrics** (`internal/metrics`): `kukatko_library_*` gauges gain a `project` label = slug (never the name); the collector iterates active projects; pool/queue metrics stay instance-wide. Update any Grafana dashboard JSON in the repo (or in `rpi`/`vps` if referenced from docs — only note it in the task notes, do not edit other repos) to sum over the label.
- **Audit**: `GET /audit` (maintainer) gains `?project=<slug>` and a `project` column; project admins get `GET /p/{slug}/audit` (and `/audit/mine`) listing only that project's entries. Add a test helper used by the api packages' tests that fails when a project-scoped mutation writes an audit entry without `ProjectUID`; run it across the api packages and fix what it finds.
- **Access log**: the structured request log includes `project` (slug) when resolved.
- Tests: template goldens, push payload URL, metrics label per project, audit filter isolation (admin of A never sees B), the audit-entry guard.
- Docs: `docs/API.md` (audit filters), `docs/PACKAGES.md`, `docs/OPERATIONS.md` (metrics label).

## Out of scope

New notification kinds; removing aliases.
