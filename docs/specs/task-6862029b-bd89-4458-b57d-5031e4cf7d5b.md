# Review Game UI v2 — Rounds, Breathers, Swipe (Frontend)

Make sessions last longer: the game runs in short rounds with visible progress, non-question breather cards, reveal moments, and swipe input on phones. Today's UI is an endless belt of similar questions and players quit early.

## Requirements
- **Rounds:** the game consumes the queue's rounds (~10 questions; the backend provides round boundaries and summary counts — see docs/API.md; if the API lacks rounds, stop and report). Within a round: a progress indicator (e.g. 4/10) and a combo counter of consecutive answers — skips reset the combo, undo adjusts it. Between rounds: a mini-summary card (confirmed/rejected/skipped this round) and a single-tap "Ještě kolo?" (Enter/→ continues). Leaving mid-round loses nothing — answers keep persisting one by one as today.
- **Breather cards:** non-question cards supplied by the backend (roughly one per round) render distinctly: a beautiful photo with title/year ("jen pro radost"), or a reveal card after confirmed work ("Alois Skoták má teď 27 fotek · nejstarší 1962" linking to the person). Breathers need no answer — any key/tap moves on; they never count into progress or combo.
- **Session milestones:** a subtle visual celebration at 10/25/50 answers in one session, consistent with the dark theme, no sound. An end-of-session summary when the queue is exhausted or the player leaves the game: totals plus a small mosaic of photos they touched, linking into the library.
- **Swipe on touch devices:** swipe right = Ano, left = Ne, down = Nevím, with visible drag feedback (the card follows the finger, direction hint colors before release). Buttons remain; existing keyboard shortcuts (→/←/space, y/n, o) keep working exactly as today — guard against key-collision regressions covered by existing tests.
- **Daily flavor (light):** the first round of the day is titled "Dnešní mix"; finishing it shows "Pro dnešek splněno ✓" while still allowing to continue. Show a 🔥 day-streak in the game header and as a new column on the leaderboard (the leaderboard API provides the streak — render only).
- Today's fullscreen layout invariants survive: no scrolling, the photo shrinks before text/buttons do, phone landscape works, 44 px touch targets under hover:none.
- i18n cs/en for everything new, Czech first ("Ještě kolo?", "Pro dnešek splněno", "jen pro radost").
- Component tests: round progress and between-round summary, combo/skip/undo, breather cards not advancing counters, swipe fires the right verdicts without breaking keyboard input, milestone triggers, streak column rendering, mid-round leave persists answers.
