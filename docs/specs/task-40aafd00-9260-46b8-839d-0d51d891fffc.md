# HLS encoder plan and playlist rendering

The pure half of HLS: what to ask ffmpeg for, and how to turn what it produces into the playlists
a player is served. No database, no HTTP, and ffmpeg is never executed here — that is the next
task. Everything in this task must be testable on a machine without ffmpeg installed.

Depends on the HLS groundwork task, which created `internal/hls` and its object layout.

## Contract (shared with the follow-up tasks)

One rendition for now, named `1080p`, but the code models a **list**: adding `720p` later must be
configuration plus data, never a rewrite. Segments target 6 seconds. Output is fMP4/CMAF with an
`init.mp4` init segment and `%05d.m4s` media segments.

## Requirements

- `internal/hls` gains a rendition description — name, the box its output is fitted into, the
  video bitrate ceiling — and a function producing the ffmpeg argument list for it.
- The scale filter fits the source inside a **square** box so landscape and portrait both cap
  correctly: a 3840x2160 source becomes 1920x1080 and a 2160x3840 source becomes 1080x1920.
  Nothing is ever upscaled, and both dimensions stay even.
- Keyframes are forced onto segment boundaries so segments are cut where they were planned.
- Encoding parameters: H.264 high profile, preset medium, CRF 21, bitrate ceiling 6 Mbit/s, AAC
  stereo at 128 kbit/s, 6 s fMP4 segments, VOD playlist.
- A media-playlist rewriter takes the playlist ffmpeg wrote and returns it with every segment URI
  and the `EXT-X-MAP` URI replaced by a caller-supplied URL. It must not synthesise durations or
  re-derive anything: every line that is not a segment URI or an `EXT-X-MAP` is passed through
  byte for byte.
- A master-playlist builder produces the master from a list of renditions — each with bandwidth,
  resolution and codecs string — pointing at a caller-supplied per-rendition URL.
- Tests: golden-file tests for both playlist functions; argument-builder tests covering a
  landscape 4K, a portrait 4K and an already-small source; and a rewriter test proving an
  unexpected tag survives untouched.

## Implementation notes

- The rewriter exists precisely so nobody hand-writes `EXTINF` values. Resist the urge to parse
  more of the playlist than the two URI cases require.
- Keep the argument builder free of side effects — no temp dirs, no probing, no clock.
- Docs: `docs/PACKAGES.md`. The encoding parameters are a quality decision worth recording where
  a future reader will look for them.
