# Modal footers: filled teal "Zrušit" competes with the primary "Uložit"

UI/UX review finding #33 (2026-10-11). In the "Nové album" modal (and other form modals using the same footer) the cancel button is a filled teal (secondary) button sitting next to the orange primary "Uložit". Two filled buttons of similar weight make the primary action less obvious.

## Requirements
- Cancel/close buttons in modal footers use the outline-secondary (or link-style) variant across the app; the primary action stays the only filled button in the footer. Destructive confirmations keep a filled danger primary with an outline cancel.
- Apply via the shared modal footer / button convention so every form modal (album, label, saved search, upload link, task, user, relation…) is consistent; grep for `variant="secondary"` in modal footers.
- Tests: update modal tests that select the cancel button by variant/class.
