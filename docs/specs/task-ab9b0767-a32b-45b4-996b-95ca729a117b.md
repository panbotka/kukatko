# Face clusters: the "remove this face" × is tiny on desktop and a red block on phones

UI/UX review finding #17 (2026-10-11). On `/people/clusters` each cluster card lists its member faces as small thumbnails with a "remove from cluster" control. On desktop it is an ~18px red × overlapping the thumbnail's corner (hard to hit, hard to tell which face it belongs to); on phones it becomes a 44×44 red filled block under each 48px thumbnail, which dominates the card.

## Requirements
- One design for both: a circular 28–32px overlay button in the top-right corner of each face thumbnail, muted dark background with a light × glyph, danger colour only on hover/focus/active; hit area extended to 44×44 on touch via padding/pseudo-element without changing the visual size.
- The face thumbnails themselves grow to at least 64px so the overlay fits and the face is recognisable.
- Keep aria-label "Odebrat obličej ze skupiny" (and its English string) and the confirmation/behaviour as today.
- No colour literal; palette tokens only.
- Update ClustersPage tests if they query the button by class/text.
