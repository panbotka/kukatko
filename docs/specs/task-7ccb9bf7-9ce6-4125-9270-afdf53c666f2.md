# Formal register (vykání) in the Czech UI

Every outgoing e-mail now addresses the reader formally (vykání: "Dobrý den", "vás", "můžete"). The Czech UI is mixed. Many screens already use vykání, for example "Přidejte fotky do knihovny", "Zadejte hledaný výraz" and "Najděte fotky podobné…". Many others use tykání. Examples seen in pre-release walk VI:

- "Napiš komentář…" (comment box)
- "1 úkol čeká na tebe" (what's-new banner, Procházet badge)
- in-app notification titles "<name> tě zmínil(a) v komentáři u fotky"
- "Nepojmenované skupiny stejného obličeje — pojmenuj celou skupinu naráz" (/people/clusters)
- "Najdi tuhle osobu…", "Vyber osobu, kterou chceš hledat" (/faces)
- "Projdi všechny pojmenované osoby…" (/recognition)
- "Vyber osobu… Rozhoduješ ty" (/outliers)

The decision: the whole Czech UI uses vykání, like the e-mails.

## Requirements

- Convert every informal Czech string to the formal register:
  - mainly `web/src/i18n/locales/cs/common.json`;
  - also any Czech UI text built in the backend, such as notification titles stored or rendered by Go (`internal/notification`, `internal/notifydeliver`, the notification producers) and any in-app text the API returns in Czech.
- Use real vykání, not impersonal rewording. Imperatives become "-te" forms (Napište, Vyberte, Projděte), the pronouns ty/tě/ti/tebe/tvůj become vy/vás/vám/váš, and second-person singular verbs (chceš, můžeš, rozhoduješ) become plural (chcete, můžete, rozhodujete).
- Keep gender-neutral forms such as "zmínil(a)". Keep the meaning, keep strings short, and preserve every i18next interpolation placeholder and plural key exactly.
- English (`en`) strings are not touched.
- Update every test that asserts on a changed Czech string. Locale tests must still render after `changeLanguage('cs')`.
- Add a guard test over the cs locale file that fails on the common informal markers, so a new string cannot reintroduce tykání:
  - whole words: tě, tebe, tobě, ti, tvůj, tvoje, tvé, tvého, jsi, máš, můžeš, chceš;
  - imperatives ending in "-ej"/"-ni"/"-ij" at the start of a string;
  - an allow-list with reasons for genuine false positives.
- If the change touches more than one large file and threatens the 30-minute budget, do the frontend locale plus the guard first and leave the backend-built strings for a clearly named follow-up note in the commit body.
- `make check` must pass.
