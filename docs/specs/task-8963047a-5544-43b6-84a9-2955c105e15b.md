## Requirements
1. **Album detail "…" menu** (`/albums/<uid>` → "Další akce"): the entries (Stáhnout ZIP, Doporučit na úvodní stránce, Sdílet odkaz pro nahrávání, Smazat) render as stacked `btn btn-outline-secondary btn-sm` buttons inside `.kk-header-overflow-menu.dropdown-menu`, not as dropdown items. Render them as proper dropdown items (Dropdown.Item, role=menuitem, keyboard arrow navigation), danger "Smazat" separated by a divider. Same pattern on the label detail header if it shares the component.
2. **New-task modal** (library → select photos → "Zeptat se"): the header close button's accessible name is the English "Close". Use the localized "Zavřít" (react-bootstrap `closeLabel`) — and grep for other Modal/Offcanvas headers still defaulting to "Close".
3. **"Koho přidat k úkolu?" picker** (same modal → "Komu" → "Přidat"): the nested modal opens over the task modal without dimming it (the parent's fields show around it). Give the nested dialog its own backdrop above the parent. The list also offers the current user, who is always on the task as creator — leave them out (or show them as already on it).
