# Scalable Labels Index

/labels shows ~113 labels as one tall vertical list with no search and no ordering (finding N10 in docs/UX_RESEARCH.md).

## Requirements

- A search input filters labels by name as the user types; case- and diacritics-insensitive.
- A sort control: photo count descending (default), name A–Z.
- Replace the single vertical list with a scannable layout — a responsive grid of compact label cards or chips showing name + photo count.
- Search/sort state lives in URL query params ("back always works").
- Empty state for no matches; cs + en i18n for all new copy.
