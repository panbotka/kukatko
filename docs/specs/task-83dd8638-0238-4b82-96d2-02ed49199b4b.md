# Consistent e-mail subjects

The subjects of Kukátko's outgoing e-mails follow two different patterns, and one subject names the product twice. Found in pre-release walk VI on box staging with every template triggered and caught in Mailpit.

## What the subjects look like today (staging, project "Veselice")

- `Kukátko · Veselice: Registrace do Kukátka čeká na schválení` (registration_received). "Kukátko" appears twice.
- `Kukátko · Veselice: Nová registrace čeká na schválení: <username>` (new_registration_pending)
- `Kukátko · Veselice: Označili vás na fotce`, `… Nové doporučené album: …`, `… admin vás přidal(a) k úkolu: …`, `… admin vás zmínil(a) v komentáři u fotky`, `… Čekají na vás 2 úkoly` (notification kinds and digest)
- **Without the prefix:** `Přístup do projektu „Veselice“ v Kukátku byl schválen` (account_approved), `Byl pro vás založen projekt „…“ v Kukátku` (project_setup and project_admin_added), `Obnovení hesla do Kukátka` (password_reset), `Vaše uživatelské jméno v Kukátku je teď …` (username_changed).

The prefix is built in `internal/mailer/templates.go` (the helper that returns `"Kukátko · " + name + ": " + subject`).

## Requirements

- Decide on and document one rule, in a comment beside the prefix helper and in `docs/PACKAGES.md` for `internal/mailer`:
  - a mail about one project, i.e. every mail that names a project, carries the `Kukátko · <project name>:` prefix;
  - an account-level mail that names no project (password reset, username changed) carries none.
- Apply the rule to every template. In particular, account_approved, project_setup and project_admin_added name a project, so they get the prefix.
- Once the prefix is there, a subject body must not repeat the product name: no "v Kukátku" or "do Kukátka" after the prefix. Example: registration_received becomes `Kukátko · Veselice: Registrace čeká na schválení`. Reword the others the same way and keep them short and formal; every mail uses the formal register (vykání).
- Message bodies stay unchanged unless one repeats the same redundancy in its first line.
- Update the template tests to pin every subject. Add one table test that renders each template once and asserts that the word "Kukátk" occurs at most once in its subject.
- `make check` must pass.
