# Every tab is called "Kukátko"

`document.title` is `"Kukátko"` on the library, on `/people` and on a photo detail alike. It
never changes.

One of the tasks a photo gallery has to support is "find the photo I saw last week", and the
most natural route to it is browser history — which currently holds fifty indistinguishable
"Kukátko" entries. The same applies to two open tabs (opening a photo in a new tab is normal
in a gallery) and to a bookmark of a saved view.

## Requirements
- Set the document title per page: `Knihovna · Kukátko`, `<photo title> · Kukátko`,
  `<person name> · Kukátko`, `Hledání „svatba" · Kukátko`, `Album <name> · Kukátko`, and so on
  for the remaining pages.
- Use one shared hook rather than scattered `useEffect` calls, and make sure the title resets
  correctly when navigating away (no stale photo name on the library).
- The data is already on each page; do not fetch anything extra for the title.
- Titles go through i18n like the rest of the UI.

## Where it is
`web/src/components/Layout.tsx` or a shared hook used by the individual pages.

## Out of scope
No data changes.
