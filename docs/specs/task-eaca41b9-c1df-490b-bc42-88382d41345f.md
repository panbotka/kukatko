# A guard against the forgotten WHERE

## Context

Kukátko is multi-tenant with explicit `project_id` predicates. Every store has been scoped and isolation tests exist, but a future query that forgets the predicate would leak data between tenants silently. This step adds a static guard to `make check`, in the spirit of `web/src/styles/colourLiterals.test.ts` (which bans colour literals outside the palette). Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 6 ("Guard in make check"). Step 38 of 40.

## Requirements

- New package `internal/tenancyguard` with a plain Go test (no build tag, so it is part of `make check`) that:
  - walks every non-test `.go` file under `internal/` and `cmd/`, parses it with `go/parser`, and collects string literals including concatenations (`a + b`) and `fmt.Sprintf`/`strings.Join` arguments that look like SQL;
  - for each literal referencing a **root table** (`photos`, `subjects`, `albums`, `labels`, `face_clusters`, `subject_families`, `photo_tasks`, `upload_links`, `import_runs`, `saved_searches`, `notifications`, `embeddings`, `faces`, `search_history`, `instance_settings`, `announcements`, `project_invites`, `photoprism_aliases`) with `FROM`, `JOIN`, `UPDATE`, `INSERT INTO`, `DELETE FROM`, asserts the same statement mentions `project_id`;
  - keeps the root-table list in one place and asserts it equals the set of tables that have a `project_id` column in the migrations (parse `internal/database/migrations/*.sql` for `ADD COLUMN … project_id` / `project_id TEXT` within a `CREATE TABLE`), so a new root table cannot be forgotten.
- Allow-list `internal/tenancyguard/allow.txt`: lines `path:line reason`, for the legitimate unscoped statements — worker-only loaders (`photos.GetForJob`/`FilesForJob`), maintenance scan/repair, metrics collectors, reset/purge, the trash retention outer loop, backup, the rekey service. A stale entry (the line no longer holds an unscoped statement) fails the test with "stale allow-list entry".
- Run it, fix every real finding (scope the statement or add a justified entry); the walk must finish well under a second on the box.
- Docs: `docs/ARCHITECTURE.md` testing strategy (the guard, how to allow-list), `CLAUDE.md` — one rule line under the quality gate: "every statement over a root table carries `project_id`; `internal/tenancyguard` enforces it" (mind the line budget), `docs/PACKAGES.md`, package map line.

## Out of scope

Changing query behaviour beyond what a finding requires.
