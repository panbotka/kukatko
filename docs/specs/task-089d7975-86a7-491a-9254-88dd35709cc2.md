# Phone: two different "search" controls two thumbs apart

UI/UX review finding #8 (2026-10-11). On phone the top bar has a magnifier button that opens the global command palette ("Hledat fotky, lidi, alba, štítky", with recent searches), while the bottom tab bar has a "Hledat" tab that opens the `/search` page (a full-text search form). Two controls with the same icon and nearly the same label lead to two different experiences.

## Requirements
- Decide one of these and implement it consistently (preferred: the first):
  1. The bottom "Hledat" tab opens the global palette (same as the top magnifier), and the `/search` page stays reachable from the drawer under "Hledání"; the top magnifier is then removed from the phone top bar to avoid duplication.
  2. Keep both but make them distinguishable: the bottom tab is labelled "Hledání" with the page's icon, the top button keeps the magnifier and gets a visible label "Rychlé hledání".
- The chosen behaviour works with Back (closing the palette does not add history entries; opening /search does).
- Desktop is unchanged.
- Update the tab bar / navbar tests (`navItems`, `MobileTabBar`, `MobileNavDrawer`) accordingly.
