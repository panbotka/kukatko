# Switching projects as leaving a profile

Today the navbar starts with a project switcher (`web/src/components/ProjectSwitcher.tsx`, used in `Layout.tsx`): the current project's name with a red unread badge and a caret, opening a dropdown of every other project with its own badges and role, plus "Všechny projekty…". The phone drawer (`MobileNavDrawer.tsx`) repeats the same list in a "PROJEKT" section. Owner feedback (2026-10-16): it looks odd in the top-left corner. The owner wants switching to feel like leaving a profile and picking another one — the way Netflix does it — with the project chooser page (`/projects`) as the one place where you pick.

## Requirements
- **Navbar:** the top-left shows the current project as a calm identity (its name, optionally its small cover/initial) — not a dropdown with a caret. Clicking it goes to the project's library (like a brand link).
- **Switching = leaving:** a clear "Přepnout projekt" / "Opustit projekt" action (en: "Switch library") lives in the account menu (the avatar/user dropdown) and in the phone drawer's account section; it navigates to `/projects`. Only shown when the account has more than one enterable project (or is a system administrator).
- **Unread in other projects** (the feature that marks unread notifications of other projects) moves with it: a small dot/count on the avatar/user menu button and on the "Přepnout projekt" item, with an accessible label ("Nepřečtená oznámení v jiných projektech: N"). The per-project counts are shown on the chooser tiles, not in the navbar.
- Remove the per-project list from the navbar dropdown and from the drawer's "PROJEKT" section. Pages without a current project (`/system/*`, `/account`, `/projects`) show a neutral title instead of "Moje projekty" with a badge.
- Keep everything that relied on the switcher working: the page remount on project change, uploads staying in their project, keyboard shortcuts, the navbar width budget at 992 px+ (the navbar must not overflow its container — measure it), the drawer test that enumerates destinations (`MobileNavDrawer.test`) and `navItems.test`.
- Colours via palette tokens, icons via `Icon`, cs + en texts.
- Tests: vitest for the new navbar identity, the menu item visibility rules, the unread marker on the user menu, and the removed list; update existing ProjectSwitcher tests (delete the component if nothing else uses it).
- Verify visually at 1440 px and 390 px, update `docs/FRONTEND.md`.
