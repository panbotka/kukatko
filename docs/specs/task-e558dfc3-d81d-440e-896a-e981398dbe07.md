# Enter in the search box must not accept a filter-key suggestion

Typing an ordinary phrase and pressing Enter rewrites the query into an English filter key, because the key-suggestion panel highlights its first row before the reader has touched anything.

## Evidence (observed on production, 2026-08-12)

- `/search`, type `svatba u`, press Enter -> the field becomes `svatba uid:`, the URL becomes `?q=svatba+uid%3A`, and the search actually runs on the mangled query.
- Same with `po` + Enter -> `portrait:`.
- `web/src/components/search/SearchQueryInput.tsx:59` — `INITIAL_ACTIVE = { history: -1, keys: 0, values: -1 }`: the keys panel rests on index 0 while the other two rest on -1.
- `web/src/components/search/SearchQueryInput.tsx:206-212` — the Enter branch accepts a suggestion whenever `activeIndex >= 0`.
- The comment directly above that code already states the intended behaviour: nothing highlighted means the reader is submitting their own query, not accepting a proposal.

This hits Czech hard: the suggestion matches the **last token**, and there are 44 English keys in `web/src/lib/queryLanguage.ts:17-63`. Common Czech words and endings are prefixes of them — `u`->`uid`, `s`->`square`/`subject`, `po`->`portrait`, `ta`/`te`/`ti`/`ty`->`taken`/`text`/`title`/`type`, `la`->`label`/`landscape`, `ne`/`no`->`near`/`notes`, `co`->`codec`/`country`.

## Requirements

- With no suggestion deliberately highlighted by the reader, Enter submits the typed query verbatim.
- Tab still accepts the highlighted completion — the code already treats Tab as the completion key and that path must keep working.
- Arrow-key selection followed by Enter still accepts, as today.
- The three panels (keys, values, history) behave consistently on their resting state.
- Regression test: type a term whose last token is a prefix of a filter key, press Enter, assert the submitted query is byte-identical to what was typed.

## Constraints

- **No mutable operations against production data.** Read-only browsing of production is allowed for verification; writes of any kind are not.
- `make check` must pass. `make check-box` runs the same gate on the build box and is much faster.
