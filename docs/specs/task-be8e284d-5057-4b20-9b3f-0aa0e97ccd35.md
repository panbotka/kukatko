# Collapsible left sidebar (icons only)

An account can move the desktop navigation from the top bar to a sidebar on the left. The choice is "Vlevo" on the account page and is stored by `web/src/lib/navPosition.ts`; the sidebar is `web/src/components/NavSidebar.tsx`, laid out by `Layout.tsx` with `.kukatko-shell--sidebar`. Today the sidebar always shows icon plus text and takes a fixed lane of width. Users want to shrink it to an icon-only rail so photos get the space.

## Requirements

- **Toggle.**
  - The sidebar carries a collapse/expand control with a chevron icon from bootstrap-icons via the `Icon` component. Place it at the sidebar's top, by the project mark, or at its bottom.
  - Accessible name: "Sbalit menu" when expanded, "Rozbalit menu" when collapsed, with English equivalents. It reflects its state with `aria-expanded`.
- **Collapsed rail.**
  - Only icons remain: the project letter mark, every navigation item's icon, the notification bell and the account avatar.
  - Each icon keeps its accessible name, the item's label, and shows that label as a tooltip on hover and keyboard focus.
  - The active item stays visibly marked.
  - The page content takes the freed width: the shell lane shrinks to the rail width (a design token beside the existing sidebar width token). Nothing overlaps the content.
- **Grouped items** (the "Procházet" and "Nástroje" groups and the account menu) still work when collapsed. Their icon opens the group's entries as a flyout or popover beside the rail, with full labels, keyboard operable, closing on Escape and on outside click. Nothing of the navigation becomes unreachable in the collapsed state.
- **Badges** (pending tasks, unread notifications, unread in other projects) remain visible on the icons as compact badges or dots, with their counts in the accessible name.
- **Remembered.**
  - The collapsed/expanded state persists per account on this browser, exactly like the navigation position: localStorage behind a key prefix plus `accountStorageKey`, best-effort, wrapped in try/catch, the default when storage is unavailable.
  - Default: expanded.
  - Other open tabs of the same account follow the change (the same listener/storage-event pattern as `navPosition.ts`).
  - Sign-out does not clear it.
- **Scope.** Only the left sidebar (`lg` and wider). The top bar and the phone drawer below `lg` are unchanged. Switching the position back to "Nahoře" ignores the collapsed state; switching to "Vlevo" again restores it.
- Respect `prefers-reduced-motion`: animate the width change, or not at all when reduced motion is preferred.
- **Colours.** Only from `styles/palette.css` tokens (the colour-literal and contrast tests must stay green).
- **Tests (Vitest):**
  - toggle state and its `aria-expanded`/name;
  - persistence round-trip and the storage-unavailable fallback;
  - collapsed rail still exposes every navigation destination by accessible name;
  - a group's flyout opens and lists its entries;
  - badges still present when collapsed.
  - Update `MobileNavDrawer.test`/`navItems.test` only if they are affected.
- Docs: `docs/FRONTEND.md` (NavSidebar, the new storage key), plus one line in README.md's feature list.
- `make check` must pass.
