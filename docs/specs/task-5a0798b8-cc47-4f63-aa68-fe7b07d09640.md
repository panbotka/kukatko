Prepares phase 2 of docs/MIGRATION_PLAN.md. A full import of the production library will
enqueue `places` reverse-geocode jobs for roughly 6 000 photos (29 % of the sampled catalogue
carries GPS: 82 of 280). Every reverse geocode spends a mapy.com credit.

## What already exists (verified, do not rebuild)

- `maps.geocode_rate_per_sec: 5`, `maps.geocode_burst: 10` (internal/config/config.go:884).
- `internal/placesjob`: when the local limiter has no token the job is DEFERRED, not failed —
  requeued after `DefaultRateLimitDelay` (1 minute) without burning a retry attempt.
- The place cache means a repeat location does not re-geocode.

So the per-second pacing is solved. What is missing is a **budget**.

## The gap

A rate limit bounds how fast credits are spent, not how many. At 5/s a full import drains
whatever quota the account has in about 20 minutes of steady work, with nothing to stop it and
no signal that it happened. The owner asked for the spend to be capped and spread out.

## What to build

1. A **credit budget** independent of the rate: a maximum number of geocodes per day (and/or
   per import run), configurable, default conservative. When the budget is exhausted the job
   defers like it already does for the rate limiter — the queue drains later, nothing fails.
2. **Visibility**: expose geocodes spent and budget remaining (Prometheus counter plus
   `/system/status`), so a run's credit spend can be seen while it happens, not inferred
   afterwards.
3. Confirm the deferral path cannot spin: a deferred job must not be re-claimed immediately in
   a tight loop when the budget is empty for a long time.

## Constraints

- New config keys go into the Config struct, setDefaults, config.example.yaml, the tests AND
  docs/OPERATIONS.md together — the project requires all five in one change.
- Do not weaken the existing rate limiter; this is an additional bound.

## Verification (mandatory)

- Unit tests: budget exhausted -> job deferred, not failed, and no sidecar/API call is made.
- A test that the counter reflects actual spend.
- `make check` green.
