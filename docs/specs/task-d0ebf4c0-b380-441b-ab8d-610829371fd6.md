# Instant Placeholder Painting in the Grid

Photo list and detail payloads carry a compact placeholder hash (BlurHash or ThumbHash — see docs/API.md for the field). Use it so the grid never shows gray boxes. If the payload field is missing from docs/API.md, stop and end the task as blocked instead of building against a guess.

## Requirements

- While a grid thumbnail loads, its tile shows the decoded placeholder (soft blurred colors) instead of an empty/neutral box; the real image fades in over it with no layout shift.
- Photos without a placeholder value keep today's neutral box.
- The photo detail/lightbox paints the placeholder while the large image loads, too.
- Decoding must not jank scrolling: decode lazily for visible tiles, cache decoded results, keep main-thread work tiny (tiny canvas or CSS-gradient approach — your choice).
- Zero cumulative layout shift: tile geometry never depends on image load.
- Tests for the placeholder-vs-fallback rendering logic.
