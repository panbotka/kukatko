# Installable PWA

Make Kukátko installable on phones: proper app identity, a manifest, and a service worker that never gets in the way of the API or media.

## Requirements
- **App icon — handle with care.** The repo currently ships only Vite's default `vite.svg`; there is no app identity at all. Design a simple, original Kukátko icon (a peephole/spyglass motif fits the name), committed as a source SVG plus generated PNGs. It must be dark-theme friendly and consistent with the app's Superhero-based look. Do NOT reuse vite.svg, do NOT copy an icon from any icon set (the bootstrap-icons rule covers in-app glyphs, not the app identity), and no runtime downloads of assets.
- **Manifest:** name "Kukátko", short_name, description, lang cs, display standalone, start_url "/", stable id, theme_color and background_color matching the app's dark surfaces, icons in 192/512 including a maskable variant. Linked from index.html together with a favicon set, apple-touch-icon (180×180), and a theme-color meta tag.
- **Service worker:** precache the built app shell (hashed Vite assets + index.html) so the shell loads instantly. API requests (`/api/...`), media, downloads, and video routes must BYPASS the service worker entirely — no caching, no interference with Range requests or auth. Navigation requests fall back to the cached shell when offline; a simple i18n "you are offline" state is enough (full offline browsing is out of scope).
- **Updates:** a new deployment must reach users without a stuck stale shell — implement a sane update flow (activate on next load, or an i18n refresh prompt).
- **iOS:** apple-touch-icon and appropriate meta so "Add to Home Screen" yields a standalone app with the correct icon and title.
- Verify Chromium's installability criteria pass and document how to re-check in docs/DEVELOPMENT.md.
- Tests: unit-test the testable glue (e.g. SW registration behind a flag), and make sure `make check` and the production build embed all new assets. Restore `internal/web/static/dist/.gitkeep` if the frontend build eats it.
- Update docs/FRONTEND.md and README.md (user-visible feature).
