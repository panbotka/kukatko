# Trash header: unlabelled "Vybrat | 180 | dní | Smazat starší než… | Vyprázdnit koš"

UI/UX review finding #16 (2026-10-11). The `/trash` header packs a "Vybrat" button, a bare number input showing "180", a "dní" addon, a red outline "Smazat starší než…" button and a red outline "Vyprázdnit koš" button into one input group. There is no label explaining the number; on 390px it wraps into three ragged rows and at 320px four.

## Requirements
- Separate the two concerns: "Vybrat" (selection mode) stays next to the page title; the retention purge becomes a small labelled form, e.g. a label "Smazat fotky starší než" + number input + "dní" + one button "Smazat", visually grouped (card or inline form with the label above on phones).
- "Vyprázdnit koš" stays a separate danger action, right-aligned on desktop, full-width (or in a "…" menu) on phones.
- The number input is at least 16px font, has an accessible label (not placeholder-only) and keeps its validation/confirm behaviour.
- Nothing wraps into more than two rows at 390px and no horizontal scroll at 320px.
- Update TrashPage tests for the new labels.
