# Choosing and switching the project

## Context

Kukátko is multi-tenant: a person can be a member of several projects. The SPA runs under `/p/:slug/…` with `ProjectProvider` (`useProject()` → `{project, projects, status, switchProject}`), `useProjectPath()`, an entry rule (`/` → last used → only one → `/projects`) and a placeholder `/projects` page. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 3.3; read `docs/FRONTEND.md`. Step 10 of 40. UI rules: Czech default + English via i18next; icons only through the `Icon` component; colours only through `styles/palette.css` tokens; respect the navbar width budget and the mobile drawer (`components/Layout.tsx`, `HeaderActions.tsx`, `MobileNavDrawer.tsx`, `navItems.ts`).

## Requirements

- `/projects` chooser (signed-in shell, outside the project `Layout`): one card per membership — name, description (clamped to 3 lines), the role as a badge; click → `/p/<slug>/`. Inactive project: greyed card, badge "Nedostupné"/"Unavailable", not clickable. Unapproved membership: badge "Čeká na schválení"/"Awaiting approval", not clickable. No memberships: empty state "Nejste členem žádného projektu. Požádejte správce projektu o pozvánku." / English equivalent. A maintainer sees an extra link "Správa projektů" → `/system/projects` (page exists in a later step; link anyway).
- Header switcher: current project name in the leading block of the navbar (truncate with ellipsis at narrow widths; measure against the width budget noted in `docs/FRONTEND.md`). With >1 membership it is a dropdown: the other approved active projects (name + role badge) and a last item "Všechny projekty…" → `/projects`. With exactly 1 membership: static text, no caret, no menu.
- Switching keeps the current route when it is a **list** route (library, favourites, albums, labels, tasks, search, saved, map, places, people, leaderboard, upload, activity, stats, help, notifications) and goes to the destination's home for any route carrying a uid (photo, album, subject, task, notification, cluster…). Encode this as a pure function `routeAfterSwitch(currentPath, fromSlug, toSlug): string` with unit tests.
- Mobile drawer: the switcher at the top of `MobileNavDrawer`; update the drawer enumeration test and `navItems.test` together.
- `document.title` = `<page> · <project name> · Kukátko`.
- Tests (Vitest): chooser renders normal / inactive / pending / empty; switcher static vs dropdown; `routeAfterSwitch`; drawer test.
- Docs: `docs/FRONTEND.md` (ProjectChooser, ProjectSwitcher, `routeAfterSwitch`), `docs/UX_AUDIT.md` one entry, `README.md`.
