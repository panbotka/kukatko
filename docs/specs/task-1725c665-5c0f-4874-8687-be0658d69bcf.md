# Every page load fetches a font from Google

`web/src/main.tsx` imports `bootswatch/dist/superhero/bootstrap.min.css`, whose first line
is `@import url(https://fonts.googleapis.com/css2?family=Lato:wght@300;400;700&display=swap)`.
That import survives into the built bundle in `internal/web/static/dist/assets/`, so the
single self-contained binary still reaches out to Google on every page load.

## Evidence

Network log of a plain page load on a fresh instance:

```
GET https://fonts.googleapis.com/css2?family=Lato:wght@300;400;700&display=swap  200
GET https://fonts.gstatic.com/s/lato/v25/S6uyw4BMUTPHjxAwXjeu.woff2              200
```

## Why it matters here

Kukátko is a self-hosted family archive. Two consequences follow:

- Every viewer's IP address and referrer are sent to Google on every page load, for a
  library whose whole premise is that the photos stay on the owner's own hardware.
- An instance on a LAN, behind a firewall, or otherwise without egress silently loses its
  typeface and falls back to whatever the browser has.

## Requirements

- The application must render its intended typography with no outbound request to
  `fonts.googleapis.com` or `fonts.gstatic.com`.
- Ship the font with the binary, the same way the rest of the frontend is embedded, so a
  fresh deployment needs no extra files or network access.
- Include the weights the interface actually uses; do not ship the entire family if only a
  few weights are referenced.
- Keep a real fallback stack declared, so a missing font file degrades to a sensible system
  face rather than to a default serif.
- The `@import` inherited from the Bootswatch stylesheet must no longer reach the built
  output. Check the built CSS, not just the source.

## Verification

After building, grep the built assets under `internal/web/static/dist` for
`fonts.googleapis` and `fonts.gstatic` and confirm there are no matches, then load a page
with the network blocked and confirm the typography is unchanged.

## Note

Watch the bundle size — this adds font files to the binary. Mention the before and after
size in the commit message so the trade-off is on record.
