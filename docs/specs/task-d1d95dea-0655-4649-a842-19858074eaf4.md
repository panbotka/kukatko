# Library toolbar uses three stacked rows before the grid

UI/UX review finding #5 (2026-10-11). On desktop the library (`/`, also `/favorites`, album and label detail) shows, above the photo grid: (1) the search field + "?" help + sort select + tiles-per-row stepper + Filtry button; (2) a helper sentence "Hledá v názvu, popisu a poznámce a rozumí filtrům jako year:1965, album:"Léto 2024" nebo person:Jarmila. Fulltext a sémantické hledání →"; (3) "Počet fotek a videí: 445" on the left with "Promítání" and "Uložit pohled" on the right. Together with the what's-new banner this is about 250px of chrome at 1440×900 before the first photo. The helper sentence largely repeats the input's placeholder ("Filtrovat — text, nebo filtr jako year:1965 či person:Jarmila").

## Requirements
- Drop the helper sentence under the search field. Keep its only unique part, the link to full-text/semantic search ("Fulltext a sémantické hledání →"), by moving it into the "?" query-help popover or next to the count line.
- Put the count ("Počet fotek a videí: 445") on the same row as "Promítání" / "Uložit pohled" / "Zrušit filtry" so the grid starts one row higher; on desktop the grid should begin at least 50px higher than today.
- Keep the phone layout as it is (the phone already shows one row + the count).
- Apply consistently wherever the same toolbar component is used (library, favourites, album detail, label detail, trash).
- Update the toolbar/library tests that assert on the helper text.

## Scope and verification
- UI only: search, sort, filters and the count are unchanged in behaviour.
