# Phone Share-Sheet Upload (Android + iOS)

Upload photos from the phone gallery straight through the native share sheet into Kukátko.

## Requirements
- **Precondition:** the app ships a web app manifest and a service worker (installable PWA). Extend them. If they are missing from the codebase, stop and report — do not build a parallel PWA setup.
- **Android/Chromium:** register a Web Share Target in the manifest (POST, multipart/form-data, image and video files). Sharing photos from the gallery to the installed Kukátko opens the app with those files staged in the existing upload flow (upload page with files preselected, same progress UI and limits). The service worker must hand the shared POST over to the app without caching it.
- **Auth & roles:** an unauthenticated user is routed through login, and the shared files survive the round-trip; if that proves technically impossible, show a clear i18n message and land on the upload page after login. Read-only viewers get a friendly i18n explanation that their account cannot upload.
- **iOS:** Web Share Target has historically NOT been supported by iOS PWAs. Verify the current state of support at implementation time; if still unsupported, implement the best honest fallback: the installed app opens fast to the upload page, the upload page supports the photo-library picker and paste, and the help page documents how to add photos from an iPhone. Do not fake a share extension.
- Edge cases: unsupported file type shared → clear message, nothing crashes; many files at once respect existing multi-upload limits.
- i18n cs/en. Tests: unit tests for the share-handling glue; component test that the upload page accepts pre-staged files.
- Update docs/FRONTEND.md and README.md.
