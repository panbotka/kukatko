# The face tooling is scoped by project

## Context

Kukátko is multi-tenant. `internal/people`, `internal/vectors` (filtered HNSW), `internal/facematch`, `internal/feedback` are scoped (convention: `projectUID` after `ctx`, never defaulted; foreign = 404 same shape; see `docs/PACKAGES.md` under `internal/photos`). `face_clusters.project_id` exists. Library-wide jobs will carry `project_uid` in their payload (the jobs step defines the field name `project_uid`; use exactly that). Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, sections 2.4, 2.5, 6. Step 14 of 40. Do not change thresholds.

## Requirements

- `internal/cluster` + `internal/clusterjob`: clustering runs **per project** — the `face_cluster` job payload gains `project_uid`, its dedup key includes it (coordinate with `internal/jobs/store.go` dedup indexes: if the jobs step has not landed yet, add the index change here in a migration, idempotently); union-find over HNSW neighbours filters by project; the cached per-cluster summaries are per project; the paged listing, assign and remove-face routes in `internal/clusterapi` pass the project; triggering a recluster enqueues one job per active project.
- `internal/candidates` + `candidatesapi`, `internal/sweep` + `sweepapi` (streamed NDJSON), `internal/outliers` + `outlierapi`, `internal/review` + `reviewapi` (queue + answer): per project; answering with a foreign face/subject/label uid → 404 same shape, nothing written.
- `internal/namelessjob`: the nameless catch-all subject is per project; `nameless_detach`/`nameless_restore` payloads and dedup keys gain `project_uid`; the undo-file format records the project uid and slug; the CLI entry points take `--project <slug>`.
- Isolation tests: store — clusters listing, candidates for a subject, sweep window, outliers, review queue (seed candidates in both projects, assert the queue of A never contains B's faces); HTTP — cluster assign with a foreign cluster uid, review answer with a foreign face, outliers of a foreign subject.
- Docs: `docs/PACKAGES.md` for each package, `docs/OPERATIONS.md` (`--project` on the nameless CLI).

## Out of scope

The family tree, albums/labels, duplicates, ingest.
