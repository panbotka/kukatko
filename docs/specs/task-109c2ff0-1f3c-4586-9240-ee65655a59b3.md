# Long-Press Selection on Touch Devices

Bulk curation on a phone currently means tapping photos one by one through checkboxes. Add the gesture every mobile gallery user already knows: long-press to start selecting, drag to extend.

## Requirements

- Long-pressing a grid tile enters selection mode and selects that photo. In selection mode, plain taps toggle photos as they do today.
- Keeping the finger down after the long-press and dragging across tiles adds every tile passed over to the selection (Google-Photos style). Dragging back over them deselects is NOT required — additive is enough.
- Scrolling must stay unaffected: a normal swipe scrolls, movement beyond a small threshold before the long-press timer fires cancels the long-press, and the browser context menu / text selection must not appear on long-press.
- Works with the virtualized grid; the selection count in the bulk actions bar updates live during the drag.
- Desktop mouse behavior is unchanged (this is a touch-input feature; feature-detect rather than user-agent sniff).
- Unit tests for the gesture state machine (timer, threshold, drag-over logic) as pure logic; component test for the wiring with synthetic touch events.

## Implementation notes

- Known repo gotcha: agent-browser mobile emulation lacks `pointer: coarse`, so touch-only media queries and measurements misbehave there — prefer feature detection in code and synthetic events in tests over relying on emulated device probes.
