## FamilyStrip

A new section on web/src/pages/SubjectPage.tsx (510 lines), between the header and the photo
gallery: four rows — Rodiče, Sourozenci, Partner, Děti — of round face chips.

Do not invent a presentation. The viewer's Informace panel already renders people as chips
with round face crops; reuse that. Under `canWrite` each row gains a `+`. Follow the existing
`{canWrite && <Outliers subjectUid />}` placement pattern used further down the page.

A subject with no photos is a legal, ordinary subject (design decision 2). The chip must
render without a face crop — initials — and must not look broken or missing.

Empty rows are omitted rather than shown empty, except under `canWrite`, where the `+` is the
invitation to fill them.

`new_subject` to the endpoint from task 2. Fully keyboard-operable: it will be used in long
sittings, not once.

## Traps

- React 19, strict ESLint and typed i18n: this repo has a recurring set of frontend lint
  gotchas that fail `make check`. Expect them.
- Locale tests must call changeLanguage BEFORE render, and renderPage has no ToastProvider.
- Do NOT add a per-file `afterEach(vi.restoreAllMocks)`. The global `restoreMocks` already
  runs, and doubling it makes RTL cleanup flush effects into empty mocks, producing
  `.then of undefined` flakes.
