# Grid Density Control

The library grid uses one density for every device — the same value on a 27" monitor and a phone (finding N4 in docs/UX_RESEARCH.md). Let the user choose.

## Requirements

- A density control in the library toolbar (icon button with a small menu): three levels, e.g. comfortable / standard / compact, changing the tile size / column count of the photo grid.
- Sensible per-breakpoint defaults so phones and desktops each start with a good value before the user ever touches the control.
- The choice is a device preference: persist it locally (e.g. localStorage), NOT in the URL — it must survive reloads but not leak into shared links. This is a deliberate exception to the URL-state rule, which covers view state (filters/sort/search); density is device presentation.
- Density applies everywhere the main photo grid component is used (library, search results).
- Changing density must not break virtualization and must not cause a re-fetch storm; thumbnails keep mapping to an appropriate rendition size for the new tile size.
- Tooltip on the control; cs + en i18n.
