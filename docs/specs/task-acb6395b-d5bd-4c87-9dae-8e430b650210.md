## Goal
A new notification kind, `album_featured`. When a curator features an album (the homepage "Doporučujeme" strip), every user who enabled the kind on some channel gets: "Nové doporučené album: <title>" with the album cover, linking to `/albums/<uid>`. Off by default on all channels, like every kind.

## Current state
`internal/organize/featured.go` (`FeatureAlbumAudited` / `UnfeatureAlbumAudited`) and `internal/organizeapi/featured.go` only write an audit entry. There is no notify hook. Features can expire on their own.

## What to build
1. Add the kind to the registry (all defaults off), add i18n for the preferences grid (cs + en), and add a Czech mail template.
2. Don't fan out to every user inside the request transaction. Enqueue **one** job (e.g. `album_featured_notify`, payload = album uid) in the feature's transaction. The job walks the users who want the kind and calls `Deliver` for each.
3. Rules:
   - skip the curator who featured it;
   - a **private album only notifies curator+** (the same visibility rule as the strip);
   - skip disabled accounts;
   - re-featuring an album that is already featured (an edit of its expiry) does **not** notify again;
   - unfeaturing before the job ran → the job finds the album no longer featured and sends nothing.
