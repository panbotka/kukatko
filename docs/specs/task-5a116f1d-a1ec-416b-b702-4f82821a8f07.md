# Family tree is unreadable on a phone

UI/UX review finding #15 (2026-10-11). `/people/:uid/tree` opens with the whole tree fitted into the canvas. On a 390px phone an 8-person, 3-generation tree renders cards with ~8px text and 16px avatars; nothing can be read or tapped.

## Requirements
- On open, the canvas zooms so that a person card is rendered at its natural, readable size (name at ≥14px, avatar ≥28px) and centres the focal person (the one the page is about, highlighted today with the orange border). The user pans with one finger / drag and zooms with pinch / wheel / the existing buttons; the existing "fit" button still fits the whole tree on demand.
- On desktop, if the whole tree fits at the natural card size, keep the fit behaviour; otherwise apply the same "natural size, centred on the focal person" rule.
- The helper sentence under the canvas mentions panning/pinching on touch devices in Czech and English.
- The canvas height on phones uses the available viewport height (down to the bottom tab bar) instead of a fixed height, so the tree has room.
- Tests: the initial transform centres the focal node at a scale of 1 when the tree does not fit.

## Scope and verification
- UI only: the tree data and interactions are unchanged.
