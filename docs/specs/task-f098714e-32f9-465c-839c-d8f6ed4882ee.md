Ancestors are the mirror image of the descendant walk and are bounded by construction
(2, 4, 8, 16 and so on), so they need a fixed generational grid rather than a tidy-tree
layout, and the query takes a `generations` argument. That is why the design splits the tree
by direction instead of drawing one graph.

- a direction switch (potomci / předci) whose state lives in the URL alongside the root, so
  Back still works;

  missing box — the gap is what invites somebody to fill it, and under `canWrite` it should
