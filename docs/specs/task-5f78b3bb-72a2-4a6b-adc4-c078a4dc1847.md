# Photo viewer: panel state in the URL, and flag keys that toggle

Two small consistency bugs in the photo viewer (`web/src/pages/PhotoDetailPage.tsx`), both verified on the box staging (commit 68e805e, 2026-09-06).

## 1. Only the info panel lives in the URL

The viewer has three side panels: Informace (`i`), Úpravy and Obličeje (`m`). Only Informace is reflected in the URL (`?info=1`). Opening Úpravy or Obličeje replaces the info panel visually but leaves `info=1` in the address, so a reload, a shared link or Back brings back the info panel instead of the one the person was looking at. Measured: `/photos/<uid>?sort=rating&info=1` stayed the URL while the edits panel and then the faces panel were open; a reload opened Informace.

### Requirements

- One URL parameter describes the open panel, e.g. `panel=info|edits|faces`; no panel → no parameter. Old links with `info=1` keep working (treated as `panel=info`) and are rewritten to the new form on first navigation.
- Opening, switching and closing a panel updates the URL with History `replace` semantics consistent with how `info=1` behaves today, so Back still means "step back", not "cycle through panels" (see `docs/FRONTEND.md` for the "Back always works" rules).
- Reload and Back/Forward restore the panel the URL names, including on the phone bottom-sheet variant.
- Tests: Vitest for the three panels and the legacy `info=1` link.

## 2. Flag keys set but never clear

The shortcut sheet says `p` / `r` / `v` mark thumbs-up / thumbs-down / eye. Clicking the toolbar buttons "Vybrat" / "Zamítnout" / "Prohlédnout později" toggles: clicking the active one clears the flag to none (verified via the API: click on Vybrat with flag `pick` → `none`). Pressing `p` on an already picked photo leaves it `pick`; the keyboard has no way to clear a flag.

### Requirements

- `p`, `r`, `v` behave exactly like their buttons: pressing the key of the current flag clears it, pressing another switches. The same handler should back both, so they cannot drift again.
- Update the shortcut sheet wording if "Označit" no longer describes it (e.g. "Přepnout palec nahoru / dolů / oko"), in both locales.
- Tests: Vitest for set, switch and clear through the keys, asserting the request the viewer sends.

## Out of scope

- No API change; the rating/flag endpoint already accepts `none`.
