# A way back from the account pages

Pages outside a project render a stripped navbar: only the word "Kukátko" at the left, the keyboard-shortcut button and the account menu. These are `/account`, `/account/activity`, `/help` and the system administrator's `/system/*`. The project navigation (Knihovna, Alba, …) disappears. To get back to the photos a user has to guess that the plain "Kukátko" text at the top left is a link. Seen on box staging as a project admin with one project: from `/account` the only way back is that word, which doesn't look clickable.

## Requirements

- **Remember the last project.**
  - The shell remembers the project the user was last in on this browser, per account: its slug, updated whenever a `/p/<slug>` route is shown.
  - Store it the way `web/src/lib/navPosition.ts` stores its preference: a localStorage key prefix plus `accountStorageKey`, best-effort, wrapped in try/catch.
  - If nothing is remembered, or the remembered project is no longer enterable, fall back to:
    1. the account's only enterable project, when it has exactly one;
    2. otherwise the chooser `/projects`.
- **Visible back link on every instance page for a signed-in user.**
  - Each page above shows, at the top of its content, a clear back control, e.g. a link button with the left-arrow icon and the label "Zpět do projektu Veselice", using the project's name.
  - When the fallback is the chooser, the label is "Vybrat projekt".
  - The control goes through the router, so browser Back still works as before.
- **Navbar.**
  - On these pages the navbar's leading brand shows the target project's letter mark in the same style as inside a project, and links to that project's library.
  - Accessible name and tooltip: "Zpět do projektu <name>".
  - The plain "Kukátko" wordmark may stay beside it, but it must no longer be the only way back.
  - Apply the same in the left sidebar layout and in the phone bar/drawer.
- **Role list.** On `/account`, each project named under "Role v projektech" links to that project (`/p/<slug>`).
- Do not change pages inside a project, or the public pages (login, registration, invite, upload link) where no one is signed in.
- **Tests (Vitest):**
  - the remembered-project round-trip and its storage-unavailable fallback;
  - the three fallbacks (remembered, only project, chooser);
  - the back control's label and target on `/account` and `/help`;
  - the navbar brand target on an instance page;
  - the project links in the role list.
- Docs: `docs/FRONTEND.md` (shell on instance pages, the new storage key).
- Formal Czech register in new strings (vykání).
- `make check` must pass.
