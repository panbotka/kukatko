# Featured albums ("Doporučujeme") on the homepage

Let a curator promote an album to the homepage for a limited time, e.g. "Pouť 2026" right after its photos are uploaded, so everyone opening Kukátko sees it first. It works as a promo for fresh albums or ones the community is working on together.

## Naming
- UI name (cs): **"Doporučené"** / action "Doporučit na úvodní stránce", strip heading "Doporučujeme". en: "Featured" / "Feature on homepage". Code identifiers: `featured`.

## Requirements
- **Data:** a migration adds a nullable `featured_until TIMESTAMPTZ` to `albums` (NULL = not featured), plus `featured_at`/`featured_by` for ordering and provenance. Classify per the reset rules (see memory/`internal/reset/tables.go` conventions — it is a column, not a table, but check). Only `type = 'album'` may be featured.
- **Expiry is automatic:** an album is featured while `featured_until > now()`. No job is needed to "unfeature" — every read filters by time. The expired value may stay in the row.
- **Default length 2 months:** new config key `albums.featured.default_days` (default 61) — add to Config struct, setDefaults, `config.example.yaml`, tests, `docs/OPERATIONS.md`. The UI pre-fills the date from it; the user can pick another date or "until I turn it off" is NOT offered (expiry is always set, max e.g. 1 year — reject further dates with 400).
- **Who:** feature/unfeature/extend requires the same role that may edit the album (check `organizeapi` guards). Audited in the mutation's transaction (`audit.Write`), like other album edits.
- **API:** `PUT /albums/{uid}/featured` body `{until}` (omitted until = now + default), `DELETE /albums/{uid}/featured`. Album payloads (detail + list) carry `featured_until` (null when not active). `GET /albums/featured` (RequireAuth) returns active featured albums, newest-featured first, with cover thumb URL, title, photo count — **respecting visibility** (private albums only for those who may see them; same rules as the album list). Document in `docs/API.md`.
- **Album detail page:** in the "…" menu / header actions: "Doporučit na úvodní stránce" opens a small modal with a date (pre-filled default); when featured, a badge "Doporučeno do 11. 12." and actions "Prodloužit" / "Zrušit doporučení".
- **Albums list:** featured albums get a visible badge; optional filter not required.
- **Homepage (`LibraryPage`, `/`):** a horizontal strip "Doporučujeme" above the timeline (near `WhatsNewPanel`), cards with cover (BlurPlaceholder), title, count; click → album. Hidden entirely when nothing is featured, and hidden while a search/filter is active. Mobile: horizontally scrollable, no page overflow. Colours only via palette tokens.
- **i18n** cs + en. Docs: `docs/FRONTEND.md`, README user-visible feature line.

## Tests
- Integration: feature/extend/unfeature, expired album not returned, private album hidden from a viewer without access, non-album type rejected, role guard, audit row written, date-too-far rejected.
- Vitest: strip renders/hides, album detail modal + badge, list badge.

## Out of scope / later
- Labels ("možná stejně i pro štítky") — design the API/strip so a later task can add featured labels the same way, but don't build it now.
- Notifications about a newly featured album.
