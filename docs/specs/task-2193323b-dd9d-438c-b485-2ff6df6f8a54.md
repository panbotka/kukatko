# A video is told it is a photo, everywhere

The interface was written when the library held only stills, and the wording never caught up.
Opening a video and reading the screen, confirmed on a live instance:

- the result count over a video-only search reads "Počet fotek: 7",
- the location block says "Tato fotka nemá uloženou polohu",
- the people block says "Na této fotce nejsou žádní lidé",
- the comment box invites "Napiš, co o téhle fotce víš…".

Every one of those is on a video. This is a copy pass, in both locales, over the places where the
item on screen may not be a still.

## Requirements

- Work through the viewer and the library listing and correct the wording wherever the item can be
  a video or a live photo. At minimum: the result-count line, the location block, the people
  block, the comments prompt and its empty state, the organize hints, and any confirmation or
  toast naming what was acted on.
- Prefer wording that covers both rather than branching on media type. Czech has usable
  media-neutral options, and one honest word beats two grammatical variants of a sentence that
  differ only in a noun. Branch on media type only where a neutral phrasing would read badly.
- Where a count is involved and the selection is genuinely mixed, say so — a count of seven videos
  should not be announced as seven photos. Where the selection is stills only, the existing
  wording stays exactly as it is; this task must not change what a photo-only library reads like.
- Czech is the default locale and is where the judgement lies: get the grammatical case and the
  plural forms right, and read the result aloud before accepting it. English follows the same
  decisions.
- Do not rename user-facing concepts that are correct as they are. The library is a photo library;
  the point is not to purge the word "fotka" but to stop applying it to an individual item that is
  a video.

## Scope boundary

The upload flow's own wording is a separate piece of work and is being handled there — leave the
upload page alone. This task is the viewer, the library listing and the search results.

## Tests

Assert rendered sentences rather than translation keys, for a video and for a photo, in both
locales. Include the four confirmed cases above as explicit regression cases.
