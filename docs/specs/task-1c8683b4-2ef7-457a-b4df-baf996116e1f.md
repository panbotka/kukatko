# Albums grid: cards in a row do not line up

UI/UX review finding #24 (2026-10-11). On `/albums` each card shows a 2×2 cover mosaic, the title, the description, the year span and the photo count. Descriptions wrap to one, two or three lines, so the year/count rows of neighbouring cards sit at different heights and the grid looks ragged.

## Requirements
- Clamp the description to two lines with an ellipsis (full text in a title attribute / on the detail page).
- Make each card a flex column with the meta block (years, count) pinned to the bottom, so within a row the meta lines align; cards in a row stretch to equal height.
- The title stays one or two lines (clamp at two).
- The same card component is used by any other album-card listing (e.g. "Soukromé" badge, empty album state) and must keep working.
- Tests: the description element carries the clamp class.
