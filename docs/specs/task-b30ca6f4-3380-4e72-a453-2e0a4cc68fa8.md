# Filtering on a phone happens blind

On a phone the filters open as a full-screen drawer. The drawer itself is well made — the
controls are large and legible — but:

- it has **no footer** (`.offcanvas-footer` does not exist) and contains **no button at all**
  (`[...d.querySelectorAll('button')]` returns an empty array),
- the result count is nowhere inside it — "Počet fotek: N" stays on the page underneath the
  drawer, i.e. invisible,
- the only way out is the cross at the very top, which means scrolling back up past ten
  fields.

So you set a year, a person and a rating, close the drawer, and only then discover the result
is zero — and then do the whole trip again.

## Requirements
- Add a sticky footer to the drawer with two things: a primary button carrying the **live
  result count** ("Zobrazit 227 fotek") that closes the drawer, and a secondary "Zrušit
  filtry".
- The count updates as filters change, without closing the drawer. The page already knows the
  number; it just is not rendered inside the drawer.
- When the current filter combination yields zero photos, the primary button says so and
  stays usable (closing the drawer must always be possible).
- The footer must not cover the last field — account for it in the drawer's scroll area, and
  respect the safe-area inset at the bottom of the screen.
- Czech and English translations.

## Where it is
`web/src/components/library/FilterBar.tsx` (the narrow-viewport variant).

## Notes on testing
An open Offcanvas is a portal: query it by `role=dialog` and use `within()`; siblings are not
aria-hidden, and a phone-width test needs a `matchMedia` override.

## Out of scope
No data changes.
