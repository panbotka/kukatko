Translate Czech **comments** to English in Go **test files** across the repo. Final part of the "docs & comments must be English" cleanup (CLAUDE.md § Language). README, docs, and non-test Go comments are already done.

## Scope
- Enumerate the affected files: `grep -rlIE '[ěščřžůňďť]' --include='*_test.go' . | grep -vE 'node_modules|dist'` (~37 files; `rg` is NOT installed — use `grep`).
- In each file, translate **comment prose only** (lines with `//`, or text inside `/* */`).

## MUST NOT change (functional Czech — leave exactly as-is)
- **Czech string literals that are test inputs or expected values** — Czech photo titles/names, search queries testing unaccent/diacritics, slug expectations, Czech place names (e.g. in `internal/mapy`, `internal/organize`, `internal/people`, `internal/query`, `internal/photoapi`, `internal/ppimport`). These exercise Czech-language behavior; translating them breaks the tests. **Translate comments only, never the test data.**
- Directive/magic comments — `//go:build`, `//go:embed`, `//go:generate`, `//nolint...`, build-tag lines — leave exactly as-is.
- Czech→ASCII transliteration/folding tables (slug logic) are DATA, not prose.

## How to tell a comment from data
A Czech fragment on a `//` line describing what the code does → translate. A Czech fragment inside `"..."`/backticks, a struct literal, or an assertion's expected value → leave. If unsure whether a literal is functional, run that package's tests before and after your edit; if a test now fails, you translated a literal you shouldn't have — revert it.

## Outcome — verified, no translation needed (2026-07-29)

Every comment in every Go test file is already English. The Czech that the
enumerating grep finds is exclusively functional test data, which this spec's
"MUST NOT change" section requires to stay as-is.

Verified with the Go parser rather than grep, so a string literal can never be
mistaken for a comment:

  **8144** comments extracted.

  `Dovolená`, `Veselí nad Moravou`, `'ř'`, `"dovolena"`/`"Dovolená"`. None is
  untranslated Czech.
- A Czech-vocabulary scan (~120 function words and verbs, accented and unaccented,
  e.g. `je`/`jsou`/`když`/`pokud`/`který`/`ověří`/`vrací`/`není`) over the comment
  text of **all** `.go` files — tests and non-tests — returned zero hits, ruling
  out Czech comments written without diacritics.
- Completeness check: the AST classified all **343** grep-flagged lines as either
  comment or string literal, with **zero** lines left unaccounted for. The 298
  non-comment lines are Czech titles, labels, place names, people's names and
  search queries that exercise unaccent/diacritics behaviour.

No source file was changed, so `make check` stands on the tree as it was.
