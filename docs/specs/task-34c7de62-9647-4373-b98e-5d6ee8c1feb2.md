# Managing projects as the system admin — pages

## Context

Kukátko is multi-tenant. Backend (instance-level, maintainer): `GET/POST /api/v1/projects`, `GET/PATCH /api/v1/projects/{uid}`, `POST/DELETE /api/v1/projects/{uid}/members[/{user_uid}]`, `GET /api/v1/users`, `PATCH /api/v1/users/{uid}` (`instance_role`); errors `slug_taken`, `invalid_slug`, `slug_immutable`, `last_admin`, `self`. Frontend: `instancePath()` for instance routes, `useAuth().isMaintainer`, Czech default + English i18n, `Icon` component only, palette tokens only. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 4.3; read `docs/FRONTEND.md`. Step 23 of 40.

## Requirements

- `/system/projects` (maintainer; instance-level route; add it next to the existing system/maintenance navigation entries and update `navItems.test` + the drawer test): a table — name (link), slug (monospace), active badge, members, photos, originals (human-readable bytes), limits (human-readable or "neomezeno"), created. Button "Nový projekt" → modal: slug (live validation with the rule, hint "nelze později změnit"), name, description, max file size and total quota as numbers with a unit select (MB/GB; empty = unlimited). Errors map to field messages (`slug_taken` → "Tento slug už existuje").
- `/system/projects/:slug` detail: edit form (name, description, limits), active toggle with a confirm dialog ("Členové projekt neotevřou, data zůstanou"), button "Přidat mě jako člena" (POST members with the caller's uid, role admin; hidden when already a member), link "Členové projektu" → `/p/<slug>/members` (page comes in a later step; link anyway), and a "Úložiště" section showing `storage_prefix` with the text "v kořeni úložiště" when empty — this section is the placeholder the storage-move UI fills later.
- `/system/users`: every account — username, display name, e-mail, instance role badge, disabled badge, memberships as `slug (role)` chips; actions "Povýšit na správce systému" / "Odebrat správce" with confirm (disabled for oneself with a tooltip).
- Service module `web/src/services/projects.ts` via `instancePath`; typed responses; byte formatting through one helper shared with existing size displays if there is one.
- Tests (Vitest): table renders, new-project validation and the `slug_taken` mapping, detail edit + deactivate confirm, add-me hidden when member, users page promote/demote, nav/drawer enumeration tests updated.
- Docs: `docs/FRONTEND.md`, `README.md` ("Správce systému" paragraph).

## Out of scope

Backend changes, the members page, the storage-move controls.
