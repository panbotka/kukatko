# Raw field content shows up in the middle of Czech UI text

Several leaks on one screen (photo detail, Informace panel):

1. Under the heading "Automatický popis" there is a nicely written Czech paragraph, followed
   on its own line by:
   ```
   AI_MODEL: gemini-2.5-flash
   ```
   In the API this is part of the `ai_note` field, where the model name was appended to the
   text with two newlines during the photo-sorter import. The UI prints it verbatim.
2. Technical details show "Fotoaparát: **Unknown**" and "Objektiv: **Unknown**" — the string
   `Unknown` really is stored (not an empty value), so the row renders even for a scanned
   photo that never had a camera, in English, in the middle of a Czech table.
3. Machine-composed photo titles mix languages: `<Name> / Czech Republic / 2026`. English
   country names also appear in album names (`Czech Republic 2026`) next to Czech ones
   (`Jihovýchod`).

"Automatický popis" is the only place where the app tells the user something about the photo
content by itself. Ending that sentence with `AI_MODEL: gemini-2.5-flash` looks like a bug and
undermines trust in the rest. `Unknown` and `Czech Republic` do the same on a smaller scale.

## Requirements
- When rendering `ai_note`, drop a trailing line that starts with `AI_MODEL:`. If the model
  name should stay visible at all, it belongs in Technical details, not in the description.
- Do not render metadata rows whose value is `Unknown` or empty; alternatively show
  "Neuvedeno". Pick one rule and apply it to every row of the table.
- Render known English country names through the i18n dictionary at display time (so a title
  or album name containing `Czech Republic` shows as `Česko`), falling back to the raw string
  when there is no translation.

## Where it is
`web/src/components/photo/MetadataPanel.tsx` (renders `ai_note`),
`web/src/components/photo/TechnicalDetails.tsx`, `web/src/i18n`.

## Out of scope — important
**Display only. No data migration**: do not rewrite `ai_note`, photo titles or album names in
the database.
