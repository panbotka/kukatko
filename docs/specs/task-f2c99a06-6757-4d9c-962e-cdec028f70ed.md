# 404 page lacks the empty-state treatment used everywhere else

UI/UX review finding #32 (2026-10-11). The app's empty states (empty trash, no clusters, no duplicates, "Vše posouzeno" in the review game…) share one pattern: a round icon badge, a bold title, a muted sentence and an action button. The "Stránka nenalezena" page (`*` route) shows only a title, a sentence and an orange button with no icon, and the forbidden/offline pages may differ as well.

## Requirements
- The 404 page uses the same empty-state component as the rest of the app (icon badge with a suitable bootstrap icon, title "Stránka nenalezena", sentence, primary button "Zpět na domovskou stránku").
- Audit `/403` (ForbiddenPage) and the offline page and align them to the same component if they differ.
- Keep all texts and links; Czech and English.
- Tests: NotFoundPage renders the shared empty-state component.
