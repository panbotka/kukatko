# "What's New" Panel

Show returning users a dismissible summary of what happened in the library since their previous visit — an in-app digest, no e-mails.

## Requirements
- When an authenticated user opens the library home (`/`), a panel above the grid summarizes changes since their previous visit: number of newly added photos, newly created albums (linked by name), and newly named people (linked). If photo comments exist in the codebase, also include the number of new comments.
- Links: "X nových fotek" opens the library sorted by recently added; albums and people link to their detail pages.
- A "visit" must be robust: refreshing or navigating around must NOT reset the reference point. A new visit begins only after a period of inactivity (at least 6 hours). Choose a simple server-side mechanism (e.g. two timestamps per user) and document it.
- First-ever visit or nothing new → no panel at all.
- The panel is dismissible (close button); the dismissed state survives navigation within the same visit.
- Works for all roles including read-only viewers.
- i18n cs/en with correct Czech pluralization (1 fotka / 2 fotky / 5 fotek).
- Counts come from cheap indexed queries (creation timestamps); no full-table scans on every page load.
- Integration tests for the summary endpoint (visit rotation, counts, empty case); component tests for the panel (render, dismiss, links).
