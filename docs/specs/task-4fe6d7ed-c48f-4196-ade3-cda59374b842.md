# Project limits

## Context

Kukátko is multi-tenant. `projects.max_file_bytes` and `projects.max_total_bytes` exist (NULL = unlimited), the system admin edits them on `/system/projects`; `internal/ingest` takes the `*project.Project`; `project.Store.Usage` returns photos + `sum(file_size)`; the instance has `upload.max_file_size_mb` (0 = none) and upload links have their own `upload_links.max_file_size_mb`. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 5.1. Step 30 of 40.

## Requirements

- Effective per-file cap = the smallest non-zero of: project `max_file_bytes`, instance `upload.max_file_size_mb`, and (for upload-link uploads) the link's cap. Enforced in `internal/ingest` for the upload endpoint, the public upload-link endpoint and `kukatko import dir`: checked **before** reading the body when `Content-Length` is present, and again while streaming (abort as soon as the count exceeds the cap; never buffer to find out). Response 413 `{"error":"file_too_large","limit_bytes":N}`.
- Total quota: before storing an original, read the project's usage and refuse when `usage + incoming > max_total_bytes` with 413 `{"error":"quota_exceeded","limit_bytes":N,"used_bytes":M}`; per file in a multi-file upload (other files continue); nothing existing is deleted; concurrent uploads may overshoot slightly — documented as accepted (no locking).
- Measure `Usage` with `EXPLAIN` on the test DB after seeding 50k photo rows; if it seq-scans, add an index `(project_id) INCLUDE (file_size)` or similar and record the measurement in `docs/PERF.md`.
- Upload page: refused files are marked in the list with the reason ("Soubor je větší než povolených X" / "Projekt dosáhl limitu úložiště"); toasts translated. Public upload-link page: "Tento projekt má plné úložiště, nahrávání není možné." with no numbers.
- Project settings page (`/p/:slug/settings`): a usage bar when a quota is set (palette tokens only).
- Tests: ingest — over project cap, over instance cap, link cap still applies, quota exactly reached, quota NULL = unlimited, streaming abort; HTTP 413 bodies; `import dir` refusal; Vitest for the upload page and the public page messages.
- Docs: `docs/API.md` (413 codes), `docs/PACKAGES.md` (ingest), `docs/OPERATIONS.md` (how the three caps interact), `README.md`.

## Out of scope

Rate limits per request, counting derived files, any storage layout change.
