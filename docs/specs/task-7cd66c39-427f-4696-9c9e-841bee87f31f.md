# Instance settings editable by an administrator

Kukátko needs three instance-wide values an administrator can change at runtime without a
redeploy: whether self-service registration is open, the shared secret registration asks
for, and the Markdown text shown to a person the first time they sign in.

Follow the shape of `internal/announcement`, which already stores a single instance-wide
value in a one-row table and audits its changes.

## Requirements

- A migration adds a one-row table holding:
  - whether registration is enabled (default false)
  - the shared registration secret (text, default empty)
  - the welcome Markdown (text, default empty)
  - when it was last changed, and by which account

  The migration seeds the single row so every read finds it.
- New package `internal/settings` with `Get` and `Set`. A change is written to the audit
  trail **inside the same transaction** as the update, the way the announcement package
  does it.
- The registration secret is stored in readable form, not hashed. An administrator has to
  read it back to tell people what it is. It is therefore never returned to anyone below
  the admin role.
- New package `internal/settingsapi` with three endpoints:
  - `GET /settings/public` — no authentication. Returns **only** whether registration is
    enabled. The sign-in screen needs it before anybody is signed in, and it must leak
    nothing else.
  - `GET /settings/welcome` — any authenticated role. Returns only the welcome Markdown.
  - `GET /settings` and `PUT /settings` — admin only. The full record, secret included.
    `PUT` replaces all three values.
- `PUT` refuses to enable registration while the secret is empty: an open door with no
  lock is never what the administrator meant.

## Implementation notes

- The new table must be classified in `internal/reset/tables.go` as **preserved**, not
  wiped. It describes the instance, not the library — the same reasoning that keeps
  `announcements`, `users` and `audit_log`. Without the classification the integration
  tests in `internal/reset` fail late in the run.

## Definition of done

- Integration tests against the real test database cover: the seeded row existing, a
  round-trip of all three values, the audit entry, the anonymous endpoint returning only
  the flag, a non-admin being refused the full record, and enabling registration with an
  empty secret being rejected.
- `docs/PACKAGES.md`, `docs/API.md` and the package map in `CLAUDE.md` are updated.
- `make check` passes.
