# Make admin form modals scrollable and fullscreen on small screens

On a phone, long admin form dialogs are centred cards whose footer Save/Cancel buttons
get covered by the on-screen keyboard, and a form taller than the keyboard-shrunk
viewport is clumsy to pan.

## Current behavior

- `web/src/pages/UsersPage.tsx` (~line 216, `UserFormModal`: username, password, role,
  display-name, note textarea + footer) and (~line 402, `PasswordModal`) are
  `<Modal show onHide centered>` with NO `scrollable` and NO `fullscreen="sm-down"`.
- The same pattern is used by the shared `ConfirmModal` (e.g. via
  `web/src/pages/ImportPage.tsx` ~line 359).
- react-bootstrap defaults: the body doesn't scroll independently and the dialog isn't
  full-screen, so the keyboard can cover the footer actions.

## Requirements

- Give these admin form modals `scrollable` (so the footer stays pinned while the body
  scrolls) and `fullscreen="sm-down"` (so long forms use the whole small screen instead
  of a cramped centred card). Apply to `UserFormModal`, `PasswordModal`, and the shared
  `ConfirmModal` — but for `ConfirmModal` verify `fullscreen="sm-down"` looks right for a
  short confirm dialog (if a full-screen confirm feels heavy, at least add `scrollable`
  / keep it centred but ensure the buttons are never keyboard-covered).
- On mobile the Save/Cancel (or confirm) buttons must always be reachable without the
  keyboard hiding them.
- Preserve desktop appearance (centred dialog) — `fullscreen="sm-down"` only affects
  small screens.

## Testing

- Add/update Vitest tests asserting the modals carry the expected props / render their
  footer actions.
- `make check` must pass.
