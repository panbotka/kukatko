# Small mobile CSS guards (two independent quick fixes)

Two small, low-risk mobile fixes.

## 1. Coarse-pointer tap-target floor skips the hamburger toggle and all close buttons

- Where: the `@media (pointer: coarse)` min-size block in
  `web/src/styles/app.css` (around lines 455-478). It enumerates
  `.btn, .form-control, .form-select, .nav-link, .dropdown-item,
  .list-group-item-action, .page-link` and enforces a ~44px minimum — but it OMITS
  `.navbar-toggler` and `.btn-close`.
- Symptom: on a phone the hamburger toggle (`web/src/components/Layout.tsx`, the
  `Navbar.Toggle` → `.navbar-toggler`, ~40px) and every `.btn-close` X (announcement
  banner dismiss, the shortcuts modal / search palette close buttons, the search
  field clear, and every react-bootstrap `Modal.Header closeButton`) are small
  ~24px targets — the shell's most-used controls are the hardest to tap.
- Fix: add `.navbar-toggler` and `.btn-close` to the coarse-pointer min-size block.
  For `.btn-close`, give it a ~44px hit area via padding / a larger invisible box
  (and negative margin if needed) so the glyph stays visually small while the
  tappable area is comfortable. Check the existing `.btn-close` rules
  (`app.css` ~line 664, `tokens.css` ~line 833, used by chip close buttons) so the
  change doesn't shrink those further.

## 2. Outliers card grid overflows the viewport at 320px

- Where: `web/src/pages/OutliersPage.tsx` (around line 440) —
  `gridTemplateColumns: 'repeat(auto-fill, minmax(20rem, 1fr))'`.
- Symptom: at 320px the 20rem (320px) minimum can't shrink below the ~296px content
  area, so the outlier card grid scrolls sideways and clips cards at the right edge.
  (The sibling grids on Candidates/Sweep use 14-16rem and are safe.)
- Fix: lower the outlier card grid minimum to ~16rem (matching the sibling grids) so
  a single column always fits a 320px screen without horizontal overflow.

## Requirements

- After the fix, the hamburger toggle and all `.btn-close` buttons have a ≥44px
  touch target on coarse-pointer devices, and the outliers page does not scroll
  horizontally at 320px.
- No desktop regressions; the visible glyph sizes should not visibly grow on desktop.

## Testing

- `make check` must pass. Add a test only where meaningful (these are largely CSS /
  a one-line grid change).
