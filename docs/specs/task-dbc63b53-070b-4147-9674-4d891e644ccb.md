# Collapse album-detail header actions into an overflow menu on narrow screens

The album-detail header crams up to five buttons into one row that wraps to 2-3 rows on
a phone, and the destructive "Smazat" sits inline among neutral actions.

## Current behavior

- `web/src/pages/AlbumDetailPage.tsx` (around lines 180-235): the header packs up to
  five buttons — Promítání (slideshow), Stáhnout (ZIP), Upravit, Vybrat, Smazat — in a
  `flex-wrap` row that wraps to 2-3 rows at 360px (each ≥44px tall), with the
  destructive "Smazat" inline among neutral actions. In selection mode the sticky
  `SelectionBar` similarly wraps into a tall bar.

## Requirements

- On narrow screens, keep only 1-2 primary actions visible (e.g. Vybrat and/or
  Promítání) and fold the secondary and destructive actions (Stáhnout, Upravit, and
  especially the destructive Smazat) into a single "⋯" overflow menu (a
  `bootstrap-icons` kebab/ellipsis `Dropdown`), so the header stays a single compact row.
- The destructive "Smazat" must be clearly separated (e.g. a divider + danger styling)
  inside the overflow menu, not adjacent to neutral actions.
- On desktop, keep the actions inline as today (the overflow collapse is a narrow-screen
  behavior).
- Preserve all actions and their behavior/RBAC.

## Testing

- Add/update Vitest tests asserting the overflow menu contains the secondary/destructive
  actions on a narrow viewport and the primary actions stay inline.
- `make check` must pass. Update `docs/FRONTEND.md` if a shared component is added.
