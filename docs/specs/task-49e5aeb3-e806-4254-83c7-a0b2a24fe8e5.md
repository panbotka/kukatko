# Saved searches list shows only names

UI/UX review finding #21 (2026-10-11). `/saved` lists each saved search as a row with its name (orange link) and Přejmenovat/Smazat buttons. The user cannot see what a saved search does without opening it.

## Requirements
- Under each name render the saved query string in muted, monospace-ish small text (at least 12px), truncated with an ellipsis on one line with the full text in a title/tooltip. If the saved search carries extra state beyond `q` (sort, filters), render the most relevant one as a tiny badge after the query.
- The whole row (name + query) is the link to open the search; the action buttons stay separate.
- On phones the icon-only action buttons remain; the query line wraps under the name.
- Update SavedSearchesPage tests to assert the query text renders.
