# Comment threads: mismatched "Upravit" link + red "Smazat" button under every comment

UI/UX review finding #14 (2026-10-11). On the task detail (`/tasks/:uid`) discussion (and the photo comment thread, which shares the component) each own comment shows "Upravit" as an orange text link and "Smazat" as a red outline button, permanently. In a thread of several comments this is visual noise and the pair is stylistically inconsistent. The composer's send button (orange square with a paper-plane icon) sits right of the textarea but bottom-aligned below it, so the two look misaligned.

## Requirements
- Comment actions become a quiet pair of small icon buttons (pencil, trash) with aria-labels and tooltips, same size and style, muted by default, danger colour only on hover/focus for delete. On devices with hover they may appear on hover/focus of the comment; on touch they are always visible. Keyboard users can always reach them.
- Delete keeps its existing confirmation behaviour.
- The composer's send button aligns to the textarea: same height as the single-line textarea and top-aligned with it (or placed inside the field as an end adornment).
- Apply to every place the comment thread component is used (task thread, photo info panel).
- Update the comment thread tests for the new buttons.
