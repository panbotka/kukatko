# Two pages still have 14px inputs (iOS Safari zooms on focus)

UI/UX review finding #34 (2026-10-11). A measurement across pages at 390px found inputs at 16px everywhere except `/tasks` (the "Hledat v otázkách…" search field, 14px) and `/upload-links` (the read-only link URL field, 14px). iOS Safari zooms the page when a focused input is smaller than 16px, which is disorienting.

## Requirements
- On touch/phone viewports every text input, select and textarea renders at 16px or larger. Fix the two known offenders and add a global rule (e.g. `form-control-sm` → 16px below `md`) so no small-size input slips through again.
- Desktop may keep the compact sizes.
- Add a test that renders TasksPage and UploadLinksPage and asserts the inputs do not carry a small-size class on narrow viewports, or a stylesheet test for the global rule.
