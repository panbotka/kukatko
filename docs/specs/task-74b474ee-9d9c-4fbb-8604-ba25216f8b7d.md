# ctl and MCP know the project

## Context

Kukátko is multi-tenant: every project-scoped endpoint lives under `/api/v1/p/{slug}/…`, MCP at `/api/v1/p/{slug}/mcp`; the unprefixed aliases still exist until the alias-removal step. API tokens belong to a user and work in every project they are a member of. `internal/ctl` keeps kubectl-style contexts (server + token) in `~/.config/kukatko/ctl.yaml` with `KUKATKO_SERVER`/`KUKATKO_TOKEN` overrides; earlier steps added ad-hoc `--project` flags to a few ctl commands. Design: `docs/superpowers/specs/2026-10-11-multi-tenancy-design.md`, section 3.4; read `docs/OPERATIONS.md` (ctl) and `docs/MCP.md`. Step 36 of 40.

## Requirements

- Context gains `project` (slug); precedence: `--project` flag (persistent; **do not shadow the persistent `-o` output flag**) > `KUKATKO_PROJECT` env > context. `ctl context set --project <slug>`, `ctl context current` prints it, `ctl projects use <slug>` sets it on the current context. Remove the ad-hoc per-command `--project` flags in favour of the persistent one.
- Every project-scoped command builds its path with the prefix; without a project it fails **before any request** with exactly: `no project selected: run 'kukatko ctl projects use <slug>' or pass --project`. Instance-level commands (`auth`, `jobs`, `system`, `backup`, `maintenance`, `projects`, `users`, `context`) ignore the project. `ctl projects list` without a project prints the caller's memberships (from `/auth/me`) for a non-maintainer and the full list for a maintainer.
- MCP: `internal/mcpapi` serves under the prefix; the OAuth protected-resource metadata and the 401 challenge advertise the prefixed resource URL; the server `instructions` text names the project. Through the alias (until removed) the `instructions` carry a one-line deprecation note.
- Tests: ctl path building with/without project, precedence, the exact error message; MCP integration with `internal/projecttest`: tools called through `/p/<B>/mcp` never return A's uids; challenge URL.
- Docs: `docs/OPERATIONS.md` (ctl project), `docs/MCP.md` (URL shape; one token, several projects by URL), `docs/PACKAGES.md`.

## Out of scope

Removing the aliases; new MCP tools.
